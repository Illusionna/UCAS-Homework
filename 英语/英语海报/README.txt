【Illusionna + 2025.............004 + 计算机科学与技术】

科学理念：概率论与数理统计课本上常被“查表了事”的 t 分布，其数学原理可回溯它的来源，1908 年 Gosset 以 Student 之名发表的小样本推断方法，让概率密度、累积分布与正则化不完全 Beta 函数与临界值表构建联系，使读者看见“每个数字背后的奥义”。

目标受众：数学、统计学、计算机科学、人工智能、生物医药临床试验疗效比较、农学田间配方比较试验、环境生态学水质土壤物种丰度的小样本对照、材料工程少量试样的强度、心理学量表得分差异、人类社会学问卷对照、计量经济学风险溢价回归检验、科普爱好者等。

设计灵感：2026 年 3 月 12 日，我在统计 TCP 流量传输 LLMs 生成 token 分布的时候，遇到了 Student t 检验，为了加速计算，深入了解统计课本中“查表”的原理，抽丝剥茧至 C++ 的 Boost 第三方库，于是仔细研究算法过程，撰写一篇博客介绍 t 检验临界值表构建的工程实践策略，因此本次英语海报作业采取 Biometrika 早期版式与古典学术活字印刷，以“科学小册子”的艺术呈现这个海报。

设计目的：让读者畅游数理与工程相结合的浪漫，让观众体验公式与历史叙事缝合，让表格数字背后的秘密成为科普阅读。

设计理念：古典艺术、简约唯美、科学严谨。

设计要素：米色仿古纸底、双线红框与花角、EB Garamond 衬线配 JetBrains Mono 等宽字体承载数学、§I / §II / §III 三段式呼应博客结构、现代化二维码工具、HTML + CSS + Vanilla JavaScript 渲染海报。
