# 第8章 数字几何处理概论

*本章概述数字几何处理（Digital Geometry Processing）的整体流程：从三维数据的获取与表示，到点云配准、网格数据结构、网格平滑，直至曲面参数化。*

## 一、几何处理流程

数字几何处理是一个由多个阶段串联而成的流水线，典型环节包括：

- **数据获取**：通过扫描、重建、建模等方式得到原始三维数据。
- **数据表示**：将三维形状组织为点云、体素或网格等结构。
- **配准（Registration）**：将来自不同视角或不同时刻的数据对齐到统一坐标系。
- **网格处理**：网格化、拓扑修复、孔洞填充、平滑去噪等。
- **参数化（Parameterization）**：建立三维曲面到二维平面（或其它域）的映射，服务于纹理映射等应用。

## 二、输入数据与坐标系

### 输入数据来源

几何数据可来自多种途径：

- **几何建模**：CAD、人机交互建模。
- **三维扫描**：对实体模型直接扫描。
- **医学影像**：CT / MRI。
- **计算机模拟**。

### 坐标系

- **直角坐标系** $(x, y, z)$：分为左手系与右手系。
- **球坐标系** $(r, \theta, \phi)$。
- **柱坐标系** $(r, h, \theta)$。

### 世界坐标 vs 局部坐标

- **局部坐标系（Local Coordinates）的优势**：
  - 表示简洁。
  - 同一个物体多次出现时，可以通过变换得到新的物体，即「标准体素 + 变换 = 新物体」。
  - 便于进行几何操作。
- **世界坐标系（World Coordinates）与局部坐标系之间相互转换**：
  - 通过简单的线性变换实现，如平移、旋转、缩放、剪切，以及这些简单变换的组合。
  - 变换的组合由齐次坐标（Homogeneous Coordinates）表示下的变换矩阵的乘积定义。

## 三、三维模型数据结构

### 点云（Point Cloud）

- 存储 $(x, y, z)$ 坐标，以及颜色、时间等信息。
- 来源：三维激光扫描、二维影像三维重建、三维模型逆向点云等。

### 体素（Voxel）

- 如同二维中的像素，是数字数据在三维空间分割下的最小单位。

### 网格（Mesh）

- 即多边形网格模型（Polygon Mesh）。
- 多边形称为网格的**面（Face）**，多边形的顶点也称为网格的**顶点（Vertex）**。
- 一般要求两张相邻面的公共边完全相同，即不能出现某一面的顶点落在另一面边的中间（避免 T 型连接，保证网格的**流形性**）。

## 四、多边形表示

- 用**大量平面片**表示形状（三角形、四边形等），其中**三角形最为常见**。
  - 本质：一种**线性表示形式**。
- 多边形应当**封闭**。
- 用封闭的多边形面片表示三维物体时，顶点个数与面片个数之间存在确定的关系（由欧拉公式约束）。
- 绘制方式由简到繁：线框图 → 模型直接绘制 → 光照明绘制 → Phong 明暗处理。

## 五、常见数据格式

### OBJ 格式

- 由 Wavefront 公司开发，用于动画文件描述。
- 可记录几何、颜色、纹理、材质等多种属性，并支持曲线曲面。
- 主要数据表：
  - 顶点坐标表：$v_i = (x_i, y_i, z_i)$
  - 纹理坐标表：$vt_p = (u_p, v_p)$
  - 法向表：$vn_a = (n_{xa}, n_{ya}, n_{za})$
  - 面表：$f_s = (v_i/vt_p/vn_a,\; v_j/vt_q/vn_b,\; \dots)$

### STL 格式

- STereoLithography（光固化立体造型术）。
- 仅定义几何，常用于 **3D 打印**。

### PLY 格式

- 结构简单，可以 ASCII 码格式或二进制形式存储。
- 源自斯坦福大学的「数字米开朗琪罗（Digital Michelangelo）」项目。
- 多用于 **3D 扫描**。

## 六、点云的获取与配准

### 点云的获取

- **直接采集**：例如使用深度相机（Depth Camera）。
- **从多视角 2D 图片重建点云**。

### 图像配准（Registration）

- 根据相关变换的初始猜测，对齐两个部分重叠的网格结构。

## 七、ICP：迭代最近点

### 内容概览

- **ICP：迭代最近点（Iterative Closest Points）**。
- ICP 变体分类：更快对齐、更具鲁棒性。
- 将 ICP 作为一个待最小化的函数来求解。

### 对齐 3D 数据

- 若**正确的对应关系已知**，则可直接求出正确的旋转/变换。
- 难点在于**如何找到对应关系**：用户输入？特征识别？标志（Landmark）？
- **ICP 的替代方案**：假设最近点彼此对应。
  - Iterative Closest Points (ICP) [Besl & McKay, 1992]。
  - 若起始位置「足够接近」（close enough），则迭代收敛。

### 基础 ICP 算法

给定源点云 $P$、目标点云 $Q$：

1. 在源点云 $P$ 中采样若干随机点 $p_i$（如 100 个）。
2. 对每个随机点 $p_i$，在目标点云 $Q$ 中找到距离它最近的点 $q_i$，可用 **k-d 树**进行临近查找加速。
3. 拒绝距离大于 $k$ 倍中位数的点对（剔除外点），构建损失函数：

$$E = \sum_i \lVert R p_i + t - q_i \rVert^2$$

其中 $(q_i, p_i)$ 为点对，$R$ 和 $t$ 分别为旋转矩阵和平移向量。

4. **最小化损失函数**，存在闭式解（closed-form solution，见 [Horn 1987]）。

### 图形匹配：平移

定义**重心化点集（bary-centered point sets）**：

$$\bar{p} := \frac{1}{m}\sum_{i=1}^{m} p_i, \qquad \bar{q} := \frac{1}{m}\sum_{i=1}^{m} q_i$$

$$\hat{p}_i := p_i - \bar{p}, \qquad \hat{q}_i := q_i - \bar{q}$$

求解将一个模型中心映射到另一个模型中心的**平移向量（translation vector）**：

$$t = \bar{p} - R\bar{q}$$

### 图形匹配：旋转

通过一个通用矩阵（general matrix）$A$ 来估计旋转，将非线性的旋转约束放松为线性的矩阵估计：

$$\min_{R} \sum_i \lVert \hat{p}_i - R\hat{q}_i \rVert^2 \quad\longrightarrow\quad \min_{A} \sum_i \lVert \hat{p}_i - A\hat{q}_i \rVert^2$$

最小二乘解为：

$$A = \left(\sum_{i=1}^{m} \hat{p}_i \hat{q}_i^{T}\right)\cdot\left(\sum_{i=1}^{m} \hat{q}_i \hat{q}_i^{T}\right)^{-1} \in \mathbb{R}^{3\times 3}$$

再通过 **SVD / 极分解（Polar Decomposition）**从 $A$ 中提取出正交的旋转矩阵：

$$A = U\Sigma V^{T} \quad\Longrightarrow\quad R = U V^{T}$$

### 3D 配准的先验（Prior）

配准能量通常由匹配项与先验项组成：

$$E_{reg} = E_{match} + E_{prior}$$

- **全局刚性先验**：约束变换为整体刚性运动。

$$E_{prior}(Z, R, t) = \sum_{i=1}^{n} \lVert z_i - (R x_i + t) \rVert_2^2$$

- **线性模型先验**：用线性形状模型（如统计形状模型）约束形变，形状由均值形状（Mean Shape）$m$ 加上基 $P$ 张成的形变叠加得到：

$$s = P d + m$$

## 八、网格相关基本概念

### 网格的描述

一个三角网格由面片集合与顶点集合构成：

- 一系列面片 $F = \{f_1, f_2, \dots, f_n\}$，每一个面片都是三角形。
- 一系列顶点 $V = \{v_1, v_2, \dots, v_n\}$。
- $F$ 中的每个面片是 $V$ 中顶点的有序序列，例如：

$$f_1 \to (v_1, v_2, v_3),\quad f_2 \to (v_4, v_5, v_6),\quad f_3 \to (v_7, v_8, v_9),\quad \dots$$

### 网格表示的由来

- 计算机产生的三维模型与实际获取的数据，其表示模式往往不同；图形学中需要一种**统一的表示方式**。
- 该表示需在**视觉精度**与**处理速度**之间取得可接受的平衡。
- 得益于图形硬件的快速发展，我们已能快速完成光栅化（rasterize）与三角网格渲染（render）。

### 三维数据的来源

模型的产生途径：

- 直接在几何文件中输入。
- **程序建模（procedural modeling）**：通过程序代码创建。
- 使用建模软件创建，如 3ds Max、Maya。
- 使用 **3D 扫描仪（3D Scanner）**获取真实模型。
- **照片测量法（photogrammetry）**：基于照片进行三维重构（Reconstruction）。
- 以上各类方法的组合。

### 网格化（Mesh Tessellation）

- 2D 网格化在三维网格处理中有重要应用。
- 多边形可表示成多种形式，通常需要分割成更易处理的图元（如凸多边形、三角形或四边形），这一过程称为**网格化（Mesh Tessellation）**。
- 其中，将多边形分割成三角形的形式称为**三角化（triangulation）**。

### 三角网格模型的存储

- 需要存储每个顶点的位置和所有三角面片。
- 以 OBJ 文件为例：分别存储顶点（`v`）与面片（`f`）。

## 九、三角网格的半边表示

**半边结构（Half-Edge Structure）**将每条无向边拆分为两条方向相反的半边，便于高效地进行邻接查询。

### 存储信息

- 每个**顶点**至少保存两部分信息：顶点的集合信息（坐标等）和一条从该顶点出发的半边。
- 每条**半边**需存储：
  - 该半边的目标顶点 $\text{tar}(e)$；
  - 该半边在同一三角形中的下一条半边 $\text{next}(e)$；
  - 与该半边属于同一条边的对边（孪生半边）$\text{opposite}(e)$；
  - 该半边所属的面 $\text{IncFace}(e)$。

### 数据结构定义

```c
struct HalfEdge {
    Vertex   *vert;   // 目标顶点
    HalfEdge *pair;   // 对边（孪生半边）
    HalfEdge *next;   // 下一条半边
    Face     *face;   // 所属面
};

struct Vertex {
    float    vcoord[3];  // 顶点坐标
    float    ncoord[3];  // 顶点法向
    HalfEdge *he;        // 出发半边
};

struct Face {
    HalfEdge *he;        // 该面的一条半边
};
```

### 邻接查询

由一条半边 `edge` 可直接取得其两端顶点与两侧面片：

```c
Vertex *vert1 = edge->vert;          // 目标顶点
Vertex *vert2 = edge->pair->vert;    // 起始顶点
Face   *face1 = edge->face;          // 当前面
Face   *face2 = edge->pair->face;    // 对侧面
```

**遍历一个面片上的所有半边**：

```c
HalfEdge *edge = face->he;
do {
    edge = edge->next;
} while (edge != face->he);
```

**遍历一个顶点周围的半边**（绕该顶点逆时针转一圈）：

```c
HalfEdge *edge = vert->he;
do {
    edge = edge->pair->next;
} while (edge != vert->he);
```

由这些基本操作可进一步实现：遍历使用某顶点的所有面片、查询一条边所在的面片、查询与某面片邻接的面片等。

### 三角形汤（Triangle Soups）

- 仅以一堆无连接关系的独立三角形表示形状。
- 有利于可视化，但**不利于需要流形网格的下游应用**。
- 常见的拓扑缺陷：朝向不一致（incompatible orientations）、复杂边（complex edges）、奇异顶点（singular vertex）、自相交（intersections）等。

### 填充孔洞（Hole Filling）

- 先计算一个粗糙的三角化 $T$（compute a coarse triangulation）。
- 再进行**优化与平滑（Refinement and smoothing）**，使补片与周围网格自然过渡。

## 十、拉普拉斯平滑

### 扩散方程（Diffusion）

网格平滑可建模为热扩散过程，连续形式的扩散方程为：

$$\frac{\partial}{\partial t} x = \mu \Delta x$$

其中 $\mu$ 为**扩散常量（diffusion constant）**，$\Delta$ 为**拉普拉斯算子（Laplace operator）**。

### 扩散方程的离散化

对网格顶点 $p_i$ 离散化：

$$\frac{\partial}{\partial t} p_i = \mu \Delta p_i$$

采用显式时间积分进行迭代更新，直到收敛：

$$p_i' = p_i + \mu\, dt\, \Delta p_i$$

直观上，每次迭代都把每个顶点朝其邻域顶点的平均位置移动，从而抹平高频噪声（Flow of vertex positions）。随着迭代次数增加（如 0、5、20 次迭代），网格逐渐变得光滑，但过度平滑会导致细节与体积损失。

## 十一、参数化

### 动机

- 最典型的应用是**纹理映射（Texture Mapping）**：将二维纹理图贴到三维曲面上，需要建立曲面到平面的映射。
- 参考：Lévy, Petitjean, Ray, and Maillot, *Least Squares Conformal Maps for Automatic Texture Atlas Generation*, SIGGRAPH 2002。

### 补充：体纹理与体渲染

- **体纹理（Solid Texture）**：由纹理值构成的三维数组（例如一整块大理石），利用一个 $[xyz] \to [RGB]$ 的函数把颜色映射到空间点上。实际使用时通常用**过程式定义**，无需存储整个三维颜色数组，只需一个为每个三维点产生颜色的函数。
- **体渲染（Volume Rendering）— Ray Marching 算法**：从摄像机出发向世界空间投射光线并逐步行进，沿途记录信息（如判断当前点是否在云层中）。对于没有明确边界、用**密度函数**描述的物体（如云朵），密度函数以三维坐标为输入、输出该处密度；每次采样累积密度即可得知光线穿越的厚度。

### 参数化的数学描述

参数化是一个映射 $f: X \to U$，将三维曲面上的点 $X$ 映射到参数域 $U$。其局部行为由**雅可比矩阵（Jacobian）** $J$ 刻画：

$$dX = J\, dU$$

曲面上的长度度量由**第一基本型（First Fundamental Form）** $I$ 给出：

$$\lVert dX \rVert^2 = dU^{T} J^{T} J\, dU$$

### 映射的特点

利用曲面第一基本型 $I$，设 $I$ 的特征值为 $\lambda_{1,2}$，雅可比 $J$ 的奇异值为 $\sigma_{1,2}$，二者满足 $\sigma_i^2 = \lambda_i$。据此可对映射分类：

- **等距映射（Isometric）**：完全保持长度与角度，$I = \mathrm{Id}$，即 $\lambda_1 = \lambda_2 = 1$。
- **保角映射（Conformal）**：保持角度，$I = \mu\,\mathrm{Id}$，即 $\lambda_1 / \lambda_2 = 1$。
- **保面积映射（Equiareal）**：保持面积，$\det I = 1$，即 $\lambda_1 \lambda_2 = 1$。

### 目标

- 真正的等距映射非常少见（一般曲面无法无形变地展平）。
- 因此目标是**最小化关于某一度量的形变**，并需要权衡以下方面：
  - **有效性（Validity）**：映射应为双射，避免三角形翻转（triangle flip）。
  - **边界（Boundary）**：边界是固定还是自由（fixed / free）。
  - **域（Domain）**：参数域的选择，例如球面（spherical）域。
  - **数值解（Numerical solution）**：求解是线性还是非线性（linear / non-linear）。
