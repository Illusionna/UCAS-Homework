# 第12章 光线跟踪与加速

*本章介绍光线跟踪（Ray Tracing）渲染算法的原理、各类光线-物体求交方法，以及用于加速求交的包围盒、层次包围盒（BVH）与空间分割（均匀网格、八叉树、KD 树、BSP 树）等数据结构。*

## 一、什么是光线跟踪

**光线跟踪（Ray Tracing）** 是一种利用复杂的光线相互作用来绘制三维图形的渲染算法：追踪光线从来源开始照射到物体上，再由物体反射的光线"路径"。

其效果在于能够逼真模拟真实世界：

- **光源**：自然光、漫反射光、折射光等。
- **物体材质**：镜面、透明、半透明等。
- **阴影效果**：软阴影、硬阴影等。

## 二、背景与发展

### 应用领域

- **影视 CG**：使用光线追踪可合成具有极高真实感的图像（如斯坦福大学 cs348b 渲染竞赛作品）。Pixar 公司 RenderMan 自 R19 版本起转向基于光线追踪的 **RIS**；Disney 动画部门的渲染器 **Hyperion** 也基于光线追踪。常用于生成或强化逼真的反射、折射、阴影，以及虚拟角色、火焰、烟雾、爆炸等特效。
- **游戏行业**：光线追踪逐渐得到应用。Unity 2019.3 正式支持实时光线追踪，部分 3A 游戏已加入实时光线追踪；NVIDIA 推出可硬件加速光线追踪的 **Turing** 架构，《战地 5（Battlefield V）》是首款搭载 RTX 实时混合光线追踪技术的游戏。

### 发展历史

- **1980 年，Turner Whitted** 首次提出包含光反射和折射效果的 **Whitted 模型**，并第一次给出光线跟踪算法的范例，是计算机图形学历史上的里程碑（*An Improved Illumination Model for Shaded Display*, Communications of the ACM, v.23 n.6, pp.343–349, June 1980）。该算法是其第一篇论文；Whitted 于 1978 年在北卡罗来纳州立大学（NCSU）获博士学位，2003 年当选美国工程院院士。
- **1984 年，Cook 等人**提出**分布式光线追踪（Distributed Ray Tracing, DRT）**，引入了蒙特卡洛方法。
- **1986 年，Kajiya 等人**提出**渲染方程（Rendering Equation）**，并给出了最原始的**路径追踪（Path Tracing）**算法。
- **双向路径追踪（Bidirectional Path Tracing）**：由 Lafortune 和 Willems 提出，Veach 对其做了详细描述。
- **梅特罗波利斯光照传输（Metropolis Light Transport）**：1997 年 Veach 首次将原应用于计算物理领域的 Metropolis 采样方法引入图形学。

### 现状

- **离线光线追踪**：光线追踪与颜色计算离线进行。即使设置很高的采样率与很多反射次数（烘焙 Lightmap 的时间会变长），最终仍能渲染出很好的效果。
- **实时光线追踪**：随摄像机视角变动，后端需实时发射光线重新计算光照。屏幕分辨率越高计算量越大，对 GPU 性能要求很高。
- **混合渲染管线（Hybrid Rendering Pipeline）**：充分利用光栅化、计算着色器与光线追踪各自的优势，对管线每个渲染阶段择优使用。
- **实时渲染发展方向**：把离线渲染技术应用到实时渲染，涉及反射、环境光遮蔽、阴影、透明阴影、多光源、粒子系统等。
  - **透明/半透明渲染**：顺序无关透明（Order-Independent Transparency, OIT）、可变粗糙度/折射/吸收、多 IOR 过渡（Multiple index-of-refraction transitions）。
  - **多光源处理**：基于加速结构的光源选择、基于重要性采样的光源选择（Light Importance Sampling）。
  - **全局光照**：基于面元（Surfels）、基于网格（Grid）、基于探针（Probes）。

## 三、光线投射算法（Ray Casting）

### 光线的基本假设

1. 光以直线传播（大部分情况）。
2. 光线交叉时不会相互干扰（光子之间无相互作用，忽略驻波效应）。
3. 光线从光源传播到眼睛（在路径反转下，物理性质不变）。

### 算法原理

对屏幕上每一像素执行以下 3 步：

1. 从视点出发，通过该像素中心向场景发出一条光线，求出该光线与场景中物体的全部交点。
2. 将各交点沿光线方向排序，获得离视点最近的交点。
3. 依据局部光照明模型计算该最近交点处的光亮度，并将其赋给该像素。

当所有像素处理完毕，即得到一幅真实感图形。

### 特点

- 明暗效果仅由**第一次相交**的物体表面法向、材质、视点与光照方向、光照强度等共同决定。
- 不考虑第二层及更深层次的光线，因此**不具有阴影、反射、折射等效果**。

### 伪代码

```
FOR each pixel
    Cast a ray and find the intersection point
    IF there is an intersection
        color = ambient
        FOR each light
            color += shading from this light
                     (depending on light property and material property)
        return color
    ELSE
        return background color
```

## 四、光线跟踪算法概述

光线跟踪是迄今最成功的真实感图形生成算法之一：**算法简单、真实感强、但计算量大**。其前身是光线投射（Ray Casting）算法，主要包含：光线求交（Ray Intersection）、阴影（Shadows）、透明与镜面反射（Transparence and Specular Reflection）、纹理（Textures）。

**为什么我们能看见物体？** 光（Light）可理解为一系列由光源发出、经物体反复弹射最终进入视点的光线（Rays）。**光线跟踪**即逆向跟踪：从视点出发，反向追踪光经物体之间多次反射、折射后投射到物体表面，最终进入人眼的过程。

### 添加反射与折射

光线跟踪能模拟镜面反射与折射效果：

1. 首先计算光线与场景中物体最近的交点。
2. 然后计算光线在交点处被反射和折射所产生的新光线方向（由入射方向、表面法向及介质共同决定）。
3. 对新产生的反射光线和折射光线分别继续递归跟踪。

#### 光线的反射

**反射定律**：

- 入射角 = 反射角；
- 入射光线、反射光线与表面法向量共面。

反射光线方向向量 $R$ 可按下式计算（$I, N, R$ 均为单位向量）：

$$R = I - 2(I \cdot N)\,N$$

反射光线方向与视点方向相对于法向呈对称关系。

#### 光线的折射

当光线由一种透明/半透明介质进入另一种介质时，因介质密度不同光的方向会发生偏折，即**折射**现象。

**折射定律（Snell 定律）**：入射角与折射角的正弦值之比是取决于介质的常数，称为相对折射率。设 $\eta_i$、$\eta_T$ 分别为入射、折射介质的折射率：

$$\eta_i \sin\theta_i = \eta_T \sin\theta_T$$

两边平方并利用 $\sin^2\theta = 1 - \cos^2\theta$：

$$\eta_i^2(1 - \cos^2\theta_i) = \eta_T^2(1 - \cos^2\theta_T)$$

解出折射角余弦：

$$\cos\theta_T = \sqrt{\,1 - \frac{\eta_i^2\,(1 - \cos^2\theta_i)}{\eta_T^2}\,}$$

则折射光方向 $T$ 可写为（$I$ 为入射方向、$N$ 为法向）：

$$T = -\frac{\eta_i}{\eta_T}\,I + \left(\frac{\eta_i}{\eta_T}\,(I \cdot N) - \cos\theta_T\right) N$$

### 算法流程

将显示缓冲区看成空间中由像素组成的矩形阵列，人眼透过这些像素看到场景中的物体。对每个像素 $P$ 计算其颜色：

1. 计算视点连接像素 $P$ 中心的光线延长后碰到的第一个物体的交点。
2. 使用局部光照模型（如 **Phong 模型**）计算交点处的颜色值。
3. 沿交点处的反射和折射方向继续跟踪光线。

### 递归光线跟踪原理

从相机发出的每条主光线（Primary Ray）都可在交点处产生一系列**次级光线（Secondary Rays）**：一条反射光线、一条折射光线，以及为每个光源产生一条阴影线（Shadow Ray）。

除阴影线外，这些光线都可视为普通光线，可再次被反射和折射，这种方法称为**递归光线跟踪（Recursive Ray Tracing）**。每条新光线都对其聚集处的颜色做出贡献，最终所有光线共同决定主光线穿过的像素的颜色。

### 算法伪代码

求最近交点：

```
对图像中的每一个像素 {
    创建从视点通过该像素的光线
    初始化 最近T 为无穷大，最近物体 为空
    对场景中的每一个物体 {
        如果光线与物体相交 {
            如果交点处的 t 比 最近T 小 {
                设置 最近T 为交点的 t 值
                设置 最近物体 为该物体
            }
        }
    }
    // 用 T、t 储存交点与视点的距离
```

着色与递归：

```
    如果 最近物体 为空 {
        用背景色填充该像素
    } 否则 {
        对每个光源射出一条光线，检测是否处于阴影中
        如果表面是反射面，生成反射光，递归
        如果物体透明，生成折射光，递归
        使用 最近物体 和 最近T 计算着色函数
        以着色结果填充该像素
    }
}
```

经典递归求交着色函数：

```c
IntersectColor(vBeginPoint, vDirection)  // 输入：射线起点、方向
{
    Determine IntersectPoint;
    Color = ambient color;               // 赋初值：环境光
    for each light
        Color += local shading term;
    if (surface is reflective)           // 物体可反射
        Color += reflectCoefficient * IntersectColor(IntersectPoint, ReflectRay);
    if (surface is refractive)           // 物体可折射
        Color += refractCoefficient * IntersectColor(IntersectPoint, RefractRay);
    return Color;
}
```

> 注：原课件折射分支误写为 `ReflectRay`，此处应为折射光线 `RefractRay`。

### 递归终止条件

1. 光线与环境中任何物体均不相交，或交于纯漫射面；
2. 被跟踪光线返回的光亮度对像素颜色的贡献很小；
3. 已递归到给定深度。

### 特征

- 易于表现阴影、反射、折射等引人入胜的视觉效果。
- 除基本几何体（球、锥、立方体等）外，也容易适用于更复杂的表示（多边形网格、复合形体等）。
- 递归层数越多效果越丰富（如 0 层、1 层、2 层递归的对比）。

## 五、光线求交（Ray Intersection）

### 光线的表示

光线（射线）的参数表示：

$$P(t) = R_o + t \cdot R_d$$

- $R_o = (x_o, y_o, z_o)$ 是光线源点；
- $R_d = (x_d, y_d, z_d)$ 是光线朝向，通常为单位向量；
- 参数 $t$ 表示光线到达的位置，正方向上 $t > 0$。

### 光线与平面求交

平面表示：

- 显式表示：$P_o = (x_o, y_o, z_o)$，法向 $n = (A, B, C)$；
- 隐式表示：$H(P) = Ax + By + Cz + D = 0$，即 $H(P) = n \cdot P + D = 0$。

**点到平面的距离**：当 $n$ 为单位法向量时，$P$ 到平面 $H$ 的（有符号）距离即为 $H(P)$。

给定平面 $n \cdot P + D = 0$，联立光线方程：

$$
\begin{cases}
P(t) = R_o + t \cdot R_d \\
n \cdot P(t) + D = 0
\end{cases}
$$

解得：

$$t = -\frac{D + n \cdot R_o}{\,n \cdot R_d\,}$$

最后验算 $t > 0$。

### 光线与三角形求交

实时图形学中基于三角形（三角面片）的表示十分常见，每个三角形用三个顶点坐标表示。常用步骤：

1. 判断光线是否与三角形所在平面相交；
2. 若交点存在，判断交点是否位于三角形内部。

**重心坐标（Barycentric Coordinates）**：三角形 $P_0P_1P_2$ 内一点 $P$ 可表示为：

$$P = \alpha P_0 + \beta P_1 + \gamma P_2,\quad 0 \le \alpha,\beta,\gamma \le 1,\ \alpha + \beta + \gamma = 1$$

重心坐标还可用于纹理映射、法向插值、颜色插值等。将 $\alpha = 1 - \beta - \gamma$ 代入并令其等于光线方程：

$$R_o + t R_d = (1 - \beta - \gamma)P_0 + \beta P_1 + \gamma P_2$$

整理为线性方程组：

$$
\begin{bmatrix} R_d & P_0 - P_1 & P_0 - P_2 \end{bmatrix}
\begin{bmatrix} t \\ \beta \\ \gamma \end{bmatrix}
= P_0 - R_o
$$

令 $E_1 = P_0 - P_1$，$E_2 = P_0 - P_2$，$S = P_0 - R_o$，由 **Cramer 法则**：

$$
\begin{bmatrix} t \\ \beta \\ \gamma \end{bmatrix}
= \frac{1}{\det(R_d,\, E_1,\, E_2)}
\begin{bmatrix} \det(S,\, E_1,\, E_2) \\ \det(R_d,\, S,\, E_2) \\ \det(R_d,\, E_1,\, S) \end{bmatrix}
$$

最后检查 $t > 0$ 且 $0 \le \beta, \gamma$、$\beta + \gamma \le 1$，以保证交点位于三角形内部。

### 光线与球面求交

#### 代数法

球面隐式方程（球心 $P_c$，半径 $r$）：

$$f(P) = \lVert P - P_c \rVert - r = 0$$

代入光线方程 $P(t) = R_o + t R_d$ 并展开（利用 $R_d$ 为单位向量，$R_d \cdot R_d = 1$）：

$$t^2 + 2t\big(R_d \cdot (R_o - P_c)\big) + (R_o - P_c)\cdot(R_o - P_c) - r^2 = 0$$

记为 $t^2 + 2bt + c = 0$，解得：

$$t = -b \pm \sqrt{b^2 - c}$$

#### 几何法

代数法可改进：实际上不需要计算被挡住的第二个交点。几何法可快速判断光线与球是否相交、光源是否在球内、光线方向是朝向还是远离球面。步骤如下：

1. 计算光线起点到球心的向量 $\vec{l} = P_c - R_o$。
2. 判断起点是否在球内：$\lVert l \rVert^2 < r^2$ 在内部，$> r^2$ 在外部，$= r^2$ 在球面上。
3. 找到光线上距球心最近点对应参数 $t_P = \vec{l} \cdot R_d$。若起点在球外且 $t_P < 0$，说明球在光线起点后方，**不相交**。
4. 计算最近点到球心距离平方 $d^2 = \lVert l \rVert^2 - t_P^2$。若 $d > r$，**不相交**。
5. 求最近点与交点的距离 $t' = \sqrt{r^2 - d^2}$，则：
   - 起点在球外：$t = t_P - t'$；
   - 起点在球内：$t = t_P + t'$。

### 光线与多边形求交

一个 $n$ 边形由 $n$ 个有序顶点列表 $v_0, v_1, \dots, v_{n-1}$ 表示，$n$ 条边为 $v_0v_1, v_1v_2, \dots, v_{n-1}v_0$，所有顶点共面：

$$\pi_p:\ n_p \cdot x + d_p = 0$$

步骤：先计算光线与多边形所在平面的交点；若交点存在，再判断其是否在多边形内部。为简化处理，将交点及所有顶点投影到 XY、YZ、ZX 三个平面之一。

**交点检测算法（Crossing Test，又称奇偶检测）**：基于 **Jordan 曲线定理**——平面上一点在多边形内部，当且仅当从该点出发的任意一条射线与多边形边界的交点数为**奇数**。
- 多边形内的点与边界相交 1 次；
- 多边形外的点与边界相交 0 次或 2 次。

该算法是所有不进行预处理的方法中最快的。

## 六、阴影（Shadows）

从交点 $P$ 向光源 $L$ 发射一条**阴影测试光线 $R$**：

- 若 $R$ 在到达 $L$ 途中与场景中物体不相交，则点 $P$ 受光源 $L$ 直接照射；
- 反之，$P$ 被位于它与 $L$ 之间的某物体遮挡；
- 若遮挡物为不透明体，则 $P$ 位于光源的阴影之中。

计算阴影时**只关心是否相交，不关注最近交点**。将阴影判定纳入光照计算即得**包含阴影的 Phong 模型**。

## 七、走样与反走样

### 走样（Aliasing）

走样是用离散量（像素）表示连续量（图形）而引起的失真：

- 数学上的点、直线无宽度与面积，而像素有面积。
- 光栅图形的走样现象：阶梯状边界、图形细节失真、狭小图形丢失、动画序列中时隐时现产生闪烁。

### 反走样（Anti-aliasing）

- **超采样（超级采样抗锯齿，SSAA）**：把当前分辨率成倍提高，再缩放回显示器分辨率。用更多采样点逼近可得更好效果。
- **自适应超采样**：仅在像素位于物体边沿时进行超采样，减少缓存与存储带宽的消耗。

## 八、纹理（Texture）

在不同表面添加多样化纹理，可使绘制结果更逼真（如地面加棋盘格纹理）。

**二维纹理（以矩形表面为例）**：

1. 为矩形四个顶点指定二维纹理坐标；
2. 用**双线性插值**计算矩形内部光线交点的二维纹理坐标；
3. 用该坐标在纹理图上查找，按结果赋予交点相应颜色值。

## 九、光线跟踪符合物理原理吗？

真实的光子由光源出发，经场景物体弹射最终进入观察者眼睛。而光线跟踪做的是**反向（Backward）跟踪**：对视点处的光线进行跟踪，直到追溯到光源。

- **前向（Forward）光线跟踪**：由光源出发跟踪光子轨迹，但经弹射最终能抵达视点的光线极少，效率很低。改进做法是每次弹射都发出一条指向视点的光线，但仍然低效。
- 光线跟踪实际上使用许多巧妙的 **Trick** 来近似真实物理效果。例如计算半透明物体阴影时，直接将光的颜色乘以遮挡物的透明因子来近似阴影，而忽略了光的折射。

## 十、为什么需要加速

光线跟踪时间复杂度很高：

- **大量光线**：每像素引出一条光线并递归。
- **大量物体/片元**：早期算法的可见性与求交测试需遍历所有物体或面片，对 $N$ 个物体时间复杂度为 $O(N)$。
- **昂贵的求交测试**：每条光线都需遍历所有物体做相交测试。

### 加速思路

1. **降低每条光线跟踪的代价** = 相交测试代价 × 相交测试次数 → 重点是**减少相交测试次数**；
2. **减少光线数量**。

**分治技巧**：与多数搜索问题类似，光线与物体的求交可用分治减少求交测试次数，将时间复杂度降为**亚线性**。常用策略与数据结构：包围盒、均匀格点法、四叉树、八叉树、空间二分树（BSP）、有向包围盒、三维 DDA 等。

## 十一、包围盒技术（Bounding Volume）

将每个物体（或片元）与其包围区域（Bounding Volume）关联：

- 若光线**未**与包围区域相交，则一定不与物体相交（省去不必要的求交测试）；
- 若光线与包围区域相交，再继续判断是否与物体相交并计算交点位置。

光线与包围区域的相交测试更快，因此能避免大量不必要的物体求交测试。

### 包围盒类型

- **轴向包围盒（AABB, Axis-Aligned Bounding Box）**：盒面法向与坐标轴平行，构建简单，但不能随物体旋转。
- **方向包围盒（OBB, Oriented Bounding Box）**：同为六面体，但面方向不要求与轴平行。可由物体表面顶点经**主成分分析（PCA）**获得特征向量作为包围盒主轴，进而构建。

包围区域也可以是包围球、包围凸多面体等。合适的包围区域应紧贴物体，以更大程度减少不必要的求交测试。

### 包围盒求交：基于 Slab 的快速算法

一个 **Slab** 指两个平行平面；将平行平面放在一组以加快计算。每个长方体由三组相对的面（3 个 Slab）构成。算法（以 2D 示例，3D 相同）：

对每个 Slab（$i = 0, 1, 2$），计算其两平面与光线的交点，按参数 $t$ 大小排序得 $t_i^{min}$ 与 $t_i^{max}$。然后取：

$$t_{min} = \max(t_0^{min}, t_1^{min}, t_2^{min})$$
$$t_{max} = \min(t_0^{max}, t_1^{max}, t_2^{max})$$

判断条件：

$$t_{min} < t_{max} \ \Rightarrow\ \text{相交}$$

若 $t_{min} < t_{max}$，则光线与长方体相交，$t_{min}$ 为射入交点、$t_{max}$ 为射出交点；否则不相交。该思想与 **Liang–Barsky 裁剪算法**类似。

## 十二、层次包围盒（BVH）

**层次包围盒（Bounding Volume Hierarchy, BVH）**：当物体数量庞大时，逐一遍历所有包围盒的相交检测开销大，因此引入二叉树结构来索引包围盒。

### 数据结构

BVH 是二叉树：

- **叶节点**表示物体或片元；
- **内节点**表示包围盒；
- 每个父节点包围盒包含其两个子节点的包围盒，根节点包围盒包含所有物体。

### 相交测试

从根节点开始递归搜索：

1. 若光线与当前节点包围盒相交，继续与子节点做相交检测；
2. 若光线与当前节点不相交，返回 false（不相交）；
3. 若光线与（叶节点的）物体相交，返回 true。

### 构建

1. 求得所有物体的包围盒；
2. 将物体分为两组，分别求出各组包围盒；
3. 递归执行第 2 步，直到达到递归深度或组中只剩一个物体。

**分组（分割点）策略**：

1. 从（空间）中点分割；
2. 排序后按物体个数平均分为两组；
3. 直接使用建模时的层次化结构。

## 十三、空间分割技术（Spatial Subdivision）

### 原理

- 将景物空间分割成一个个小的空间单元；
- 被跟踪的光线仅与它所穿过单元中所含的物体表面做求交测试；
- 利用相邻单元的空间连贯性，使光线快速跨越空单元、迅速到达非空单元，求得第一个交点。

典型方法：均匀网格、KD 树、BSP 树、四叉树（2D）/ 八叉树（3D）。

### 均匀格点法（Uniform Grid）

将空间分为均匀单元（体素），光线沿传播路径向前追踪，直到与某单元中的对象相交。

**构建步骤**：

1. 找到物体的包围盒；
2. 划分网格；
3. 对与物体重叠的单元格，存储所有重叠的物体。

**遍历（求交）**：按光线传播路径用 **3D DDA** 遍历经过的网格；对每个通过的网格，计算光线与该网格中所有物体的交点；检测到单元内交点即停止。二维情形中，光线与水平线、竖直线的交点在各自方向上等间距，便于计算交点坐标及所在单元。

**实现注意事项**：

- **避免重复记录**：物体可能覆盖/跨越多个单元，可在单元中用指针记录物体，避免重复记录。
- **避免重复检测**：标记已检测过的物体或片元，避免后续单元再次检测。
- **交点不在当前单元内时不能直接返回**：需继续向前追踪，可能存在更近的相交物体。

**格点分辨率影响**：

- 单元格过少（如仅一个）：无加速效果；
- 单元格过多：网格遍历开销导致效率低下；
- 单元格适中：较好的加速效果。

**优缺点**：

- 优点：容易构造、容易进行光线跟踪。
- 缺点（以下情形开销较大）：物体片元在空间中整体稀疏分布、或在空间局部聚集。

为应对非均匀分布，引入**非均匀空间细分**：KD 树（k-dimensional tree）、八叉树（oct-tree）、二叉空间分割树（BSP-tree）等。

### 八叉树（Octree）

- 一个父节点有 8 个子节点，对应一个立方体区域分割为 8 个等大小立方体；
- 叶子节点是物体或片元；
- 对细节复杂的区域可自适应细分。

**问题**：子立方体只能被均匀分割。当物体在空间中非均匀分布时，构建出的八叉树会不平衡。
**解决方案**：允许分割平面位置可变，不局限于立方体的平分面——由此引入 KD 树。

### KD 树（k-dimensional tree）

**节点存储内容**：

- 中间节点：划分坐标轴（x/y/z）、划分位置（划分平面在该轴上的坐标）、子节点；
- 叶子节点：物体信息列表、包围盒。

**建立过程**：

1. 找到包围盒；
2. 使用与坐标轴平行的平面划分包围盒；
3. 直到满足停止条件（如最大划分数、最少物体数）；
4. 将物体信息存储于叶子节点中。

**求交过程**（以 x 轴划分平面、方向向右的光线为例，递归进行）：

1. 与格子 A 相交；
2. 与包围盒 1 相交，但不与物体相交；
3. 与格子 B 相交；
4. 与包围盒 2 相交，但不与物体相交；
5. 与包围盒 3 相交，判断是否与物体相交；
6. 与包围盒 3 中物体相交，计算具体交点。

### 空间二分树（BSP Tree）

**空间二分树（Binary Space Partitioning Tree）**：

- 与 KD 树相比，分割平面可取**任意方向**（KD 树只能与坐标轴平行）；
- 是目前许多游戏环境中空间细分的行业标准。
