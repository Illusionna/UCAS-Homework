## 三、重点公式 / 算法速查（按"易考"标注）

> ⭐ = 常考简答/计算/证明题方向

### 渲染与光照
- ⭐ **Phong 光照模型**：`第6章` 环境+漫反射+镜面反射 $I = I_a k_a + I_d k_d(\mathbf{l}\cdot\mathbf{n}) + I_s k_s(\mathbf{r}\cdot\mathbf{v})^p$
- ⭐ **渲染方程**：`第13章` $L_o(\mathbf{x},\omega_o)=L_e+\int_\Omega f_r(\omega_i,\omega_o)L_i(\omega_i)(\omega_i\cdot\mathbf{n})\,d\omega_i$
- ⭐ **BRDF 定义与三性质**（线性 / 可逆性 / 能量守恒）：`第13章`
- **反射/折射方向**（Snell）、**俄罗斯轮盘赌无偏证明**：`第12章 / 第13章`

### 几何变换
- ⭐ **MVP 变换链** $M_{Projection}\cdot M_{View}\cdot M_{Model}$、**透视/正交投影矩阵**：`第6章`
- ⭐ **法向量变换** $(M^{-1})^T$ 推导：`第6章`
- ⭐ **链式坐标变换**（局部↔世界、子↔父齐次矩阵）：`第4章`

### 光栅化
- ⭐ **Bresenham 画线**（误差递推）、**中点画圆**判别式：`第7章`
- **扫描线多边形填充**、**Z-buffer / 画家算法**消隐：`第7章`

### 几何处理
- ⭐ **ICP**：能量函数 + **SVD 闭式解**（Kabsch）：`第9章`
- ⭐ **PCA 法向估计**（协方差最小特征值）：`第9章`
- ⭐ **QEM 二次误差简化**、**Loop 细分系数 $\beta$**：`第10章`
- ⭐ **拉普拉斯坐标 / 微分编辑**、**ARAP 能量 + local-global**：`第11章`
- **Marching Cubes**（256→15 索引表）、**泊松重建**：`第9章`

### 动画
- ⭐ **LBS 线性骨骼蒙皮** $\mathbf{v}'=\sum_i w_i T_i \mathbf{v}_0,\ \sum w_i=1$：`第15章`
- ⭐ **关键帧插值**（线性/样条）、**质点弹簧 + 欧拉积分 / PBD**：`第15章`
- ⭐ **3DMM 人脸模型**（形状/纹理线性组合 + 多线性张量）：`第15章`

### 加速结构
- ⭐ **AABB 包围盒 Slab 求交**、**BVH 层次包围盒**：`第12章`
- ⭐ **KD 树 / 八叉树 / 均匀网格**空间分割对比：`第12章`
