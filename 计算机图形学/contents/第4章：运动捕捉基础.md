## 什么是运动捕捉

运动捕捉（**Motion Capture**，简称 Mocap）的几种代表性定义：

- "……记录运动以便在线或离线的分析或重现……" —— David J. Sturman
- "现场表演的 3D 表示重建" —— Alberto Menache
- "……是一种在娱乐、体育和医疗应用等方面以数字形式记录动作的技术。" —— Wikipedia

## 动捕历史

### Eadweard Muybridge（1830—1904）

- 第一个拍摄记录运动序列的人。
- 通过连续摄影清晰地展现出：无论是小跑还是飞奔，马的四只马蹄会同时离开地面（著名的"飞奔的马"序列）。
- 拍摄了大量动物与人的行走运动，留下约 2 万张有关男人、女人、儿童、动物和鸟类的照片。

### 影像描摹（Rotoscoping）

- 由 **Max Fleischer** 于 1915 年发明。
- 允许动画师在真人表演的照片上**逐帧追踪描绘**卡通人物，是一种 **2D 手动运动捕捉**。
- "影像描摹可以被认为是动作捕捉的原始形式或先驱，其中动作是通过手工精心'捕捉'的。" —— Sturman
- 代表作品：第一个被影像描摹的卡通人物——"小丑科科"（Koko the Clown）；以及人物动画《白雪公主和七个小矮人》（沃尔特·迪斯尼，1937）。

## 动捕技术

### 当前的动捕技术概览

所谓"**3D 影像描摹**"，即测量物体的 3D 位置、方向、速度或加速度。当前主流的动捕系统按传感原理可分为：

- 电磁传感式
- 机械（机电）式
- 光纤式
- 光学式

### 基于电磁传感的动捕

原理：每个传感器记录 3D 位置和方向，传感器放置在运动物体的关节上；全身运动捕捉至少需要 15 个传感器。（代表系统：Ascension Technology）

- **优势**
  - 能测量 3D 位置和旋转
  - 没有遮挡问题
  - 能同时捕捉多人
- **缺点**
  - 易受磁扰动影响（金属）
  - 捕获范围（捕获量）小
  - 无法捕捉细微形变（如脸部表情捕获）
  - 难以捕捉小骨骼的运动（如手指运动）
  - 精度不如光学捕捉系统

### 机械式动捕

原理：每个传感器捕捉 3D 旋转，传感器放置在运动物体的关节上；全身运动捕捉至少需要 15 个传感器。（代表系统：Xsens）

- **优势**
  - 能测量 3D 旋转
  - 没有遮挡问题
  - 能够同时捕获多人
  - 较大的捕获范围
  - 支持户外捕捉（如滑雪）
- **缺点**
  - 不容易获取 3D 位置坐标
  - 无法捕捉细微形变（如脸部表情捕获）
  - 难以捕捉小骨骼的运动（如手指运动）
  - 精度不如光学捕捉系统

### 光纤动捕

原理：通过贴绑在身上的光纤（磁带）测量其整条的 3D 位置和旋转。（代表系统：Measurand）

- **优势**
  - 能测量 3D 旋转和位置
  - 没有遮挡问题
  - 能够同时捕获多人
  - 不受捕获场地的限制
  - 能捕获手和手指的运动
- **缺点**
  - 侵入式的捕获
  - 无法捕捉细微形变（如脸部表情捕获）
  - 精度不如光学捕捉系统

### 光学动捕

原理：

- 使用多个标定相机（≥8 台）从不同视角捕获表演运动。
- 表演者穿戴贴有**反光标记点**（marker）的材料。
- 系统准确测量各标记点的 3D 位置。

特点：

- **优点**
  - 能测量 3D 位置和旋转
  - 是最精确的捕获方法
  - 高帧率
  - 可以捕获非常细致的动作（身体、手指、面部变形等）
- **缺点**
  - 受遮挡影响大
  - 难以捕获多人互动
  - 捕获范围有限

### 基于单目相机的光学动捕

- 基于多目相机及反光材料的运动捕获方法需要昂贵的设备，以及繁琐的后处理工作。
- 近年来随着深度学习的兴起，依据**单帧图像估计人体姿态**的方法蓬勃发展。
- **单目深度相机**因具有测量物体绝对距离、保护照片隐私等特点，在单目运动捕获方面相较于 RGB 相机具有更大的优势。
- 相关研究：*Weakly Supervised Adversarial Learning for 3D Human Pose Estimation from Point Clouds*（TVCG 2020）；*Probabilistic Triangulation for Uncalibrated Multi-View 3D Human Pose Estimation*（ICCV 2023）。

## 动捕流程（以光学动捕为例）

光学动捕的整体流程为：**制定计划 → 标定 → 数据处理**。

### 制定计划

运动捕捉前需要一系列的计划制定，核心理念是"垃圾进、垃圾出"（Garbage In, Garbage Out），需预先规划如何使用数据。

- 预计如何使用数据
- 相机镜头安排
- **故事板（Storyboard）**
  - 动作必须能够彼此融合衔接
  - 捕捉基本动作和过渡动画
  - 明确哪些运动过渡到哪些运动
  - 规划循环运动
- **角色 / 道具设置**
  - 角色骨架拓扑（骨骼/关节数、每个骨骼的自由度）
  - 道具的位置和大小
- **标记点设定**
  - 标记点个数
  - 标记点放置位置

### 标定

- **相机标定**
  - 确定每个摄像机的位置和方向
  - 确定相机内参（例如焦距）
- **人物标定**
  - 确定演员的骨架大小（生成 `.asf` 文件）
  - 确定标记点相对关节的位置
  - 确定道具的大小和位置

### 处理标记点

- 每个摄像机分别记录捕获内容。
- **提取（Detection）**：需要在图像中识别出标记点，确定其 2D 位置。
  - 问题：遮挡导致部分标记点不可见 → 利用更多的相机缓解。
- **编号（Labeling）**：为标记点确定编号（这个标记点是几号？）。
  - 问题：轨迹交叉时标记点编号可能发生互换 → 可能需要人工干预修正。
- **计算 3D 位置（三角化）**：如果某标记点至少被 2 台摄像机同时观测到，则可以确定其在 3D 空间中的位置。

### 数据处理流水线

得到 3D 标记点位置后，处理流程为：

`3D 标记点位置 (.c3d)` → `补全缺失标记数据` → `动捕数据过滤处理` → `计算 3D 标记点的运动轨迹 (.c3d)` → 经**逆向运动学（Inverse Kinematics, IK）**求解 → `关节角度数据 (.amc)`

核心问题：**如何在关节角度空间中表示运动数据？**（即如何把世界坐标系中的 3D 标记点轨迹，通过逆运动学转化为各关节的局部旋转角度。）

## 动捕数据结构

### 人体运动的表示

- 一段动画即随时间变化的一系列姿态：$q_1, q_2, \dots, q_T$。
- 每个姿态都表示为一个高维向量，例如 $q \in \mathbb{R}^{62}$（由根关节的位置、朝向加上各关节的旋转角度构成）。

### 动捕数据文件

人体运动数据的每个序列包含两个文件（均由 Vicon 软件生成）：

- **骨架文件（`.asf`）**：指定角色的骨架模型（默认姿态、骨长、层次结构等）。
- **运动数据文件（`.amc`）**：指定每一帧各关节的角度值。

## 链式结构与坐标变换原理

### 链式结构（2D 示例）

以一个 2D 台灯模型为例：连杆 $l_0, l_1, l_2, l_3$ 依次相连，各关节有旋转角 $\theta_0, \theta_1, \theta_2, \theta_3$。在默认姿态 $(0,0,0,0,0,0)$ 下，末端点 $A$ 处于初始位置。

### 复合 2D 旋转

要计算链式结构末端点 $A$ 在世界坐标系下的位置，需将根部平移、各关节旋转与连杆平移依次复合（先平移到关节、旋转、再平移到下一节）：

$$
p = T(x, y)\,R(\theta_0)\,T(0, l_0)\,R(\theta_1)\,T(l_1, 0)\,R(\theta_2)\,T(l_2, 0)\,R(\theta_3)\,p_0
$$

其中：

- $T(\cdot)$ 为平移变换，$R(\theta)$ 为旋转变换；
- $p_0$ 为末端点在最末端局部坐标系下的位置；
- **ASF 默认姿态**对应各关节旋转为默认值时的坐标；**AMC 文件中的关节角**则给出每帧的实际旋转角度，代入同一公式即可得到该帧世界坐标系下的位置。

## 人体骨架文件（.asf）

人体骨架是一个**树状结构**（根关节为根，各肢体为分支）。描述这样一个骨架，需要明确每个骨骼的以下信息。

### .asf 描述的内容

- **个体骨架信息**
  - 骨长（length）
  - 骨骼朝向（direction）
  - 局部坐标系（axis）
  - 自由度个数（dof）
  - 关节限制（limits，生理约束）
- **骨骼层次 / 连接关系**（hierarchy）

### 单个骨骼的定义示例

```
begin
  id      bone_id        /* 每个骨骼的唯一 id */
  name    bone_name      /* 每个骨骼的唯一名称 */
  direction dX dY dZ     /* 骨骼在世界坐标系下的方向向量 */
  length  7.01722        /* 骨骼长度 */
  axis    0 0 20 XYZ     /* 该骨骼局部坐标系相对世界坐标系的旋转。
                            .amc 文件中该骨骼每帧的旋转角度，
                            都是相对于此局部坐标系定义的 */
  dof     rx ry rz       /* 该骨骼的自由度 */
  limits  (-160.0 20.0)  /* 各自由度的关节角范围（生理约束）*/
          (-70.0 70.0)
          (-60.0 70.0)
end
```

实际示例（左大腿 lfemur）：

```
begin
  id 2
  name lfemur
  direction 0.34 -0.93 0
  length 7.01722
  axis 0 0 20 XYZ
  dof rx ry rz
  limits (-160.0 20.0)
         (-70.0 70.0)
         (-60.0 70.0)
end
```

要点说明：

- `axis` 定义该骨骼局部坐标系 $(x_k, y_k, z_k)$ 相对世界坐标系 $(x_w, y_w, z_w)$ 的固定旋转。该旋转可用**欧拉角（Euler angles）**表示：$R = R_z(\gamma)\,R_y(\beta)\,R_x(\alpha)$。
- `dof` 给出**关节的自由度个数**；关节可分为 1 自由度、2 自由度、3 自由度三类。
- `limits` 给出每个自由度的最大、最小旋转角，对应人体生理约束。

骨骼间存在父子关系，例如 lfemur（大腿，id 2）的子骨骼为 ltibia（小腿，id 3，仅 1 个自由度 `rx`，关节限制 `(-10.0 170.0)`），其局部坐标系 $(x_{k+1}, y_{k+1}, z_{k+1})$ 嵌套在父骨骼坐标系内。

### 根关节表示

根关节（root）单独定义，包含 3 个平移自由度和 3 个旋转自由度：

```
:root
order TX TY TZ RX RY RZ
axis XYZ
position 0 0 0
orientation 0 0 0
```

由此引出核心问题：**如何计算世界坐标系中各关节的坐标？**——需要沿骨架树从根关节逐级向下做坐标变换。

### 骨骼连接（层次结构）

`:hierarchy` 段以缩进/列表形式描述树状连接关系，每行第一个为父骨骼，其后为其所有子骨骼：

```
:hierarchy
  begin
    root      lhipjoint rhipjoint lowerback
    lhipjoint lfemur
    lfemur    ltibia
    ltibia    lfoot
    lfoot     ltoes
    rhipjoint rfemur
    rfemur    rtibia
    rtibia    rfoot
    rfoot     rtoes
    lowerback upperback
    upperback thorax
    thorax    lowerneck lclavicle rclavicle
    …
  end
```

对应的左腿分支为：`root → lhipjoint → lfemur → ltibia → lfoot → ltoes`。

### .asf 文件能做什么

- 可视化默认姿态。
- 在默认姿态下计算各种坐标变换：
  - 世界坐标系与局部坐标系之间的转换；
  - 父子节点坐标系之间的转换。

## 坐标变换

### 由局部坐标系到世界坐标系

骨骼 $k$ 局部坐标系下的点 $X_k$ 变换到世界坐标系下的点 $X_w$：

$$
X_w = R_k X_k + T_k
$$

其中 $R_k$ 为该骨骼局部坐标系到世界坐标系的旋转，$T_k$ 为其平移（原点位置）。

### 由子节点到父节点

设父骨骼为 $k-1$、子骨骼为 $k$，二者各自满足：

$$
X_w = R_{k-1} X_{k-1} + T_{k-1}, \qquad X_w = R_k X_k + T_k
$$

令两式相等，可解出子坐标系到父坐标系的变换：

$$
X_{k-1} = R_{k-1}^{-1} R_k\, X_k + R_{k-1}^{-1}(T_k - T_{k-1})
$$

写成齐次变换矩阵 $T_k^{k-1}$ 的形式：

$$
T_k^{k-1} =
\begin{bmatrix}
R_{k-1}^{-1} R_k & R_{k-1}^{-1}(T_k - T_{k-1}) \\
0 & 1
\end{bmatrix}
$$

## 运动数据文件（.amc）

`.amc` 文件按帧记录每个关节的角度值。每帧以帧号开头，随后逐行列出 `根关节的位置与朝向`、以及各关节的关节角：

```

lowerback -17.2981 -0.243065 -1.41128                  // lowerback 关节角
upperback 0.421503 -0.161394 2.20925                   // upperback 关节角
thorax    10.2185 -0.176777 3.1832
lowerneck -15.0172 -5.84786 -7.55529
upperneck 30.0554 -3.19622 -4.68899
head      12.6247 -2.35554 -0.876544
rclavicle 4.77083e-014 -3.02153e-014
rhumerus  -23.3927 30.8588 -91.7324
rradius   108.098
rwrist    -35.4375
rhand     -5.30059 11.2226
rfingers  7.12502
rthumb    20.5046 -17.7147
lclavicle 4.77083e-014 -3.02153e-014
lhumerus  -35.2156 -19.5059 100.612
…
```

关于 .amc 中关节角的约定：

- 文件中描述的是**局部坐标系下的旋转**。
- 用**欧拉角**表示，旋转顺序为 x-y-z，即合成旋转矩阵为：

$$
R = R_z(\gamma)\,R_y(\beta)\,R_x(\alpha)
$$

- 每个关节的角度数据个数与该骨骼的自由度（dof）一致。

## 复合 3D 旋转

物体的一系列旋转可以通过**旋转矩阵的连乘**来实现。要把链式骨架末端点的局部坐标 $x$ 变换到世界坐标 $p$，需要沿骨架链从根到末端，把每段的「局部坐标系固定旋转（来自 .asf）」、「当前帧关节旋转（来自 .amc）」与「骨段平移」依次复合：

$$
p = T(x_0, y_0, z_0)\,R(\alpha_0)R(\beta_0)R(\gamma_0)\,T_1^0\,R(\alpha_1)R(\beta_1)R(\gamma_1)\,T_2^1\,R(\alpha_2)\,T_3^2\,R(\alpha_3)R(\beta_3)R(\gamma_3)\,x
$$

其中：

- $p$：在世界坐标系下的位置；
- $x$：在末端局部坐标系下的位置（例如 $(h_3, 0, 0)$）；
- $T_i^{i-1}$：来自 `.asf` 文件的父子骨骼间固定变换；
- 各 $R(\cdot)$ 中，骨骼局部坐标系的固定旋转来自 `.asf`，每帧的关节旋转角度来自 `.amc`。
