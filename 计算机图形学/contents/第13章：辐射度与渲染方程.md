# 第13章 辐射度与渲染方程

*本章从辐射度量学基础出发，系统介绍双向反射分布函数（BRDF）的定义、性质与各类模型，并推导反射方程与渲染方程，最后讨论求解渲染方程的两大途径——光线追踪/蒙特卡洛 Path Tracing 与辐射度有限元方法。*

## 一、引言

**双向反射分布函数（BRDF, Bidirectional Reflectance Distribution Function）** 描述的是物体表面对光的反射性质，是绝大多数图形学算法中用于描述光反射现象的基本模型。

本章主题是：光线如何被表面反射的物理描述（即 BRDF），以及如何进行真实的全局光照渲染。主要内容包括：

- 预备知识（辐射度量学）
- BRDF 的定义与性质
- BRDF 模型
- BRDF 的度量与评价
- 反射方程与渲染方程
- 光线跟踪、蒙特卡洛方法与 Path Tracing

## 二、预备知识：辐射度量学

需要掌握的基本概念：光照（illumination）、球面坐标（spherical coordinate）、立体角（solid angle）、投影面积（foreshortened area）、光能（radiant energy）、光通量（radiant flux）、辐照度（irradiance）、辐出度（radiant exitance）、辐射强度（intensity）、辐射亮度（radiance）。

### 1. 光照现象

光学研究的内容主要分为两部分：

- **波动光学（Wave Optics）**
- **几何光学（Geometric Optics）**

**光学平面边界上的散射**：反射方向为入射方向关于平面法线的对称向量；折射方向可由 Snell 法则计算得出。反射和折射的比例由**菲涅尔方程（Fresnel Equations）**给出，菲涅尔方程比较复杂，图形学里一般使用近似公式计算。

**非光学平面边界上的散射**：光线照射到微小表面上时，同样一部分在表面发生反射。这些朝向不同的微表面把入射光线反射到不同的方向。

### 2. 光照分类

光照可分为全局和局部两种：

- **局部光照（local illumination）**：与物体直接被光源照射的情况相关。
- **全局光照（global illumination）**：与物体被光源以外其它地方来的光线照射的情况相关，包括其它物体反射和透射过来的光线。

### 3. 球面坐标（Spherical Coordinate）

由于光线主要通过方向来表达，用球面坐标比用笛卡尔坐标更方便。球面坐标中的向量用三个元素指定：

- $r$ 表示向量的长度；
- $\theta$ 表示向量和 $z$ 轴的夹角；
- $\phi$ 表示向量在 $x\text{-}y$ 平面上的投影和 $x$ 轴的逆时针夹角。

球面坐标 $\mathrm{Sph}(r,\theta,\phi)$ 与三维笛卡尔坐标 $\mathrm{Car}(x,y,z)$ 的转换公式为：

**笛卡尔坐标 → 球坐标系：**

$$r = \sqrt{x^2 + y^2 + z^2}, \qquad \theta = \arccos\!\left(\frac{z}{r}\right), \qquad \phi = \arctan\!\left(\frac{y}{x}\right)$$

**球坐标系 → 笛卡尔坐标：**

$$x = r\sin\theta\cos\phi, \qquad y = r\sin\theta\sin\phi, \qquad z = r\cos\theta$$

### 4. 立体角（Solid Angle）

立体角 $\omega$ 具有如下微分形式：

$$d\omega = \frac{dA}{r^2}$$

由于面积微元在球面坐标系下可以写成：

$$dA = (r\,d\theta)(r\sin\theta\,d\phi) = r^2 \sin\theta\,d\theta\,d\phi$$

因此：

$$d\omega = \frac{dA}{r^2} = \sin\theta\,d\theta\,d\phi$$

### 5. 投影面积（Foreshortened Area）

投影面积描述了物体表面的微小区域在某个视线方向上的可见面积。对于面积微元 $A$，沿着与法向夹角为 $\theta$ 方向的可见面积为：

$$A_{\text{proj}} = A\cos\theta$$

### 6. 辐射度量学诸量

- **光能（Radiant Energy）** $Q$：表示（一个区域中）光子能量的总和，单位为焦耳（J）。

- **光通量（Radiant Flux）** $\Phi$：光能始终不断运动，不会停留储存在某处。光通量描述单位时间穿过截面的光能，单位为瓦特（W）：

$$\Phi = \frac{dQ}{dt}$$

- **辐照度（Irradiance）** $E$：表示物体表面受光能的影响程度，等于单位面积上的光通量，单位为 $\mathrm{W/m^2}$：

$$E = \frac{d\Phi}{dA}$$

- **辐出度（Radiant Exitance）** $L$：表示物体表面沿某一方向的明亮程度，等于单位投影面积和单位立体角上的光通量。辐出度可看作发光强度 $I$ 在表面 $dA$ 上的积分。

> 辐照度和辐出度都可以称为**辐射通量密度（Radiant Flux Density）**。

- **辐射亮度（Radiance）** $L$：常需度量从一个微小面积表面出发、射向某个微小方向的通量（或来自某个微小方向、照射到微小面积表面的通量），辐射亮度就是度量这种情况的量。它使用沿目标方向的**投影面积**而非面积：

$$L = \frac{d\Phi}{dA\cos\theta\,d\omega}$$

### 7. 辐照度与辐射亮度的关系

辐照度可以写成辐射亮度在入射光所形成的半球上的积分：

$$E = \frac{d\Phi}{dA} = \int_{\Omega} L(\omega)\cos\theta\,d\omega$$

其中 $\Omega$ 是入射光所形成的半球，$L(\omega)$ 是沿 $\omega$ 方向的辐射亮度。

### 8. 各量关系总结

从光能出发，逐级求导可得到各辐射度量：

- 光能 $Q$ —（单位时间）→ 光通量 $\Phi$
- 光通量 —（单位面积）→ 辐照度 $E$；—（单位立体角）→ 辐射强度 $I$
- 辐射亮度 $L = \dfrac{E}{\text{投影系数} \times \text{立体角}} = \dfrac{I}{\text{投影面积}}$，其中投影系数为 $\cos\theta$。

## 三、BRDF 的定义

BRDF 描述的是物体表面将光能从任何一个入射方向反射到任何一个视点方向的反射特性，是绝大多数图形学算法中用于描述光反射现象的基本模型。

### 1. 物理推导

在某一点上的反射过程：从 $\omega_i$ 方向发出的辐射转化为 $dA$ 接收到的能量 $E$，该能量将成为指向任何其他方向 $\omega_o$ 的辐射。

- **入射微分辐照度**：$dE(\omega_i) = L(\omega_i)\cos\theta_i\,d\omega_i$
- **出射微分辐射亮度**（由 $dE(\omega_i)$ 产生）：$dL_r(\omega_r)$

### 2. BRDF 定义式

BRDF 是关于入射光方向和反射光方向的四维实值函数，等于反射方向的微分辐射亮度与沿入射方向入射光的微分辐照度之比：

$$f(\omega_i \to \omega_r) = \frac{dL_r(\omega_r)}{dE_i}$$

写成关于入射光辐射亮度的形式（单位为 $\mathrm{sr^{-1}}$）：

$$f(\omega_i \to \omega_r) = \frac{dL_r(\omega_r)}{L_i(\omega_i)\cos\theta_i\,d\omega_i}$$

> **为什么 BRDF 要定义成辐射亮度与辐照度的比值，而不是辐射亮度与辐射亮度之比？** 因为入射端用辐照度测量仪、反射端用辐射亮度测量仪即可测得，这一比值形式与测量过程一致且物理意义明确。

## 四、BRDF 的性质

### 1. 线性性（Linearity）

总反射辐射亮度等于各入射方向贡献的线性叠加。

### 2. 可逆性（Reciprocity）

BRDF 的可逆性源自 **Helmholtz 光路可逆性（Helmholtz Reciprocity Rule）**：交换入射光与反射光的角色，并不会改变 BRDF 的值。

$$f(\omega_i \to \omega_r) = f(\omega_r \to \omega_i)$$

### 3. 能量守恒（Energy Conservation）

BRDF 需要遵循能量守恒定律：入射光的能量与出射光的总能量应该相等。

$$Q_{\text{incoming}} = Q_{\text{reflected}} + Q_{\text{absorb}} + Q_{\text{transmitted}}$$

由此可知 $Q_{\text{reflected}} \le Q_{\text{incoming}}$。因此 BRDF 必须满足如下积分不等式（**能量守恒性质**）：

$$\int_{\Omega} f(\omega_i \to \omega_r)\cos\theta_r\,d\omega_r \le 1$$

## 五、BRDF 模型

为了方便高效地使用 BRDF 数据，往往将其组织成参数化的数值模型，主要分为三类：

- **经验模型（Empirical Models）**：使用基于实验提出的公式对 BRDF 做快速估计。
- **基于物理的模型（Physical-based Models）**：根据物体表面材料的几何及光学属性建立反射方程，从而计算 BRDF。
- **数据驱动的模型（Data-driven Models）**：将 BRDF 按实测数据建立查找表，便于快速查找和计算。

### 1. 经验模型（Empirical Models）

经验模型提供简洁的公式以便于反射光线的快速计算，特点是：

- 不考虑材质特性，仅提供反射光的粗糙近似；
- 不一定满足物理定律（如 Helmholtz 可逆性或能量守恒性质）；
- 因其简洁高效而被广泛运用。

#### （1）Lambert 漫反射模型

Lambert 模型是最基本的反射模型：入射光线被均匀地反射到各个方向，沿不同方向的 BRDF 是一个常数 $f$。

反射辐射亮度：

$$L_r(\omega_r) = \int_{\Omega} f\,L_i(\omega_i)\cos\theta_i\,d\omega_i = f\int_{\Omega} L_i(\omega_i)\cos\theta_i\,d\omega_i = f E_i$$

**反射率（Albedo）** $\rho$ 是反射辐出度与入射辐照度之比：

$$\rho = \frac{E_r}{E_i} = \frac{\int_{\Omega} L_r(\omega_r)\cos\theta_r\,d\omega_r}{E_i} = \frac{f E_i \pi}{E_i} = \pi f$$

特点：

- 能很好地描述纯粹漫反射的物体（例如纸张）；
- 不能表现镜面反射效果，而镜面反射对金属材质非常重要；
- 因其简洁，常作为分量被包含在其它经验模型（例如 Phong 模型）中。

#### （2）Phong 模型

Phong 模型在 Lambert 漫反射模型基础上添加了一项镜面反射项，以表达在反射角上的镜面反射效果：

$$f(l \to v) = \rho_d + \rho_s \frac{(r\cdot v)^s}{n\cdot l}$$

其中 $\rho_d$、$\rho_s$ 分别表示漫反射和镜面反射光线的反射率，$s$ 表示发光指数（用于描述镜面反射的锐利度），$r$ 为反射方向，$v$ 为视线方向。

特点：

- 不满足可逆性：$f(l \to v) \ne f(v \to l)$；
- 尽管缺乏物理解释、对某些金属材质不够准确，但仍是图形学中被最广泛使用的经验反射模型；
- 优势在于简洁高效，能同时表现漫反射和镜面反射特征。

绘制示例：最终效果由**漫反射 + 环境光 + 镜面反射**三个分量叠加而成。

#### （3）Phong 模型的扩展

大部分扩展是为了实现进一步的加速：

- **Blinn-Phong 模型**：引入入射方向 $l$ 与视线方向 $v$ 的角平分线（半程向量）$h$，用 $h$ 和法向 $n$ 的点积替代原先的 $r\cdot v$，可简化运算：

$$f(l \to v) = \rho_d + \rho_s \frac{(n\cdot h)^s}{n\cdot l}, \qquad h = \frac{v + l}{\|v + l\|}$$

- **快速 Phong 绘制（Fast Phong Shading）**：由 Bishop 和 Weimer 发表于 1986 年 ACM SIGGRAPH，思想是使用制表和插值的方法对指数项 $(r\cdot v)^s$ 进行快速计算，实现绘制加速。

- **可逆的 Phong 模型（Modified Phong Model）**：去掉镜面反射分量的分母项，使修改后的模型满足可逆性：

$$f(l \to v) = \rho_d + \rho_s (r\cdot v)^s, \qquad f(l \to v) = f(v \to l)$$

### 2. 物理模型（Physical-based Models）

经验模型源于设计者的直觉和实践经验，而物理模型建立在有关光相互作用的科学知识上，通过包含材料的各种几何及光学性质来尽可能精确地近似现实世界中的材料。

#### （1）微平面假设

物理模型通常建立在被称为**表面粗糙度**的细节几何结构上：

- 从微观角度看，几乎没有完全光滑的表面；
- 微观尺度的表面几何通过一组**微平面（microfacets）**集合来建模；
- 粗糙度通过微平面法向的统计分布来表达。

#### （2）Cook-Torrance 模型

假设微平面是镜面反射的，按 V 形沟槽排列。并非所有微表面都能接收到光线，也不是所有反射光线都能到达眼睛。结合微平面反射的镜面反射项为：

$$f(l, v) = \frac{F(l, h)\,G(l, v)\,D(h)}{4\cos\theta_i\cos\theta_o} = \frac{F(l, h)\,G(l, v)\,D(h)}{4(n\cdot h)(n\cdot v)}$$

其中 $F$ 是菲涅尔因子，$D$ 是微平面法向的分布函数，$G$ 是几何衰减因子，$n$ 是宏观表面法线，$h$ 是微表面法线。

**法向分布函数 $D$（Normal Distribution Function）**：描述平均表面法线周围的微平面分布，已有多种函数（如高斯分布、Beckmann 分布）。

- $m$ 值用于度量表面粗糙程度，较大的 $m$ 对应粗糙平面，较小的 $m$ 对应较光滑的表面；
- $\alpha$ 是宏观表面法线 $n$ 和微表面法线 $h$ 的夹角。

**几何衰减因子 $G$（Geometric Attenuation Factor）**：考虑来自视角方向的遮挡（masking）和来自光线方向的阴影（shadowing），用于排除被遮挡和被阴影覆盖的微平面：

$$G(n, l, v) = \min\!\left(1,\; \frac{2(n\cdot h)(n\cdot v)}{v\cdot h},\; \frac{2(n\cdot h)(n\cdot l)}{v\cdot h}\right)$$

对遮挡和阴影的考虑使模型可以产生某些反射特性：

- **离镜面反射（Off-specular reflection）**：反射方向不在镜面反射方向上，是典型的粗糙表面特征；
- **逆反射（Retroreflection）**：很大一部分光线沿反方向返回，例如满月图片的边缘看起来和中心一样明亮。

相比 Phong 模型，Cook-Torrance 模型能更真实地表现金属等材质的高光。

### 3. 其他物理模型

按反射的方向相关性，BRDF 可分为两类：

- **各向同性（Isotropic）**：反射不受与给定表面法向夹角的约束；随机表面微结构。
- **各向异性（Anisotropic）**：反射随着与某个给定表面法向之间的夹角而变化；图案化的表面微结构，如金属丝、绸缎、毛发。

更多 BRDF 类模型：

- **Oren-Nayar 模型**（*Generalization of Lambert's Reflectance Model*, ACM SIGGRAPH, 1994）：将微平面当作 Lambertian 反射体而非镜子。
- **Poulin-Fournier 模型**（*A Model for Anisotropic Reflection*, ACM SIGGRAPH, 1990）：将微平面法向表示为一组平行圆柱体，处理各向异性情况。
- **波动光学（Wave Optics）相关模型**：由波动光学原理发展而来，材料微平面大小与光波长相当，基于不同的衍射（diffraction）理论。代表工作有 He et al.（*A Comprehensive Physical Model for Light Reflection*, ACM SIGGRAPH, 1991）与 Stam（*Diffraction Shaders*, ACM SIGGRAPH, 1999）。这类模型描述能力很强，但本身过于复杂，限制了应用（如可自动正确呈现方向光源照射 CD 表面的彩色高光）。

### 4. 数据驱动的 BRDF 模型

- 度量一个大的材料集合的 BRDF，并记录为高维向量；
- 利用降维方法从数据中计算一个低维流形。
- 代表性工作：Matusik et al.（*A Data-Driven Reflectance Model*, ACM SIGGRAPH, 2003）、**MERL BRDF Database**。

### 5. 三类模型对比

- **经验模型（Empirical）**：计算简单，可产生视觉上可接受的结果。
- **物理模型（Physical-Based）**：参数具有物理意义，基于科学知识构建。
- **数据驱动模型（Data-driven）**：灵活，对材料属性无假设限定，但数据集很大，通常需要降维方法压缩数据；需要对数据插值，可能缺失高光部分。

## 六、反射方程与渲染方程

### 1. 反射方程（Reflection Equation）

某点 $x$ 沿 $\omega_r$ 方向的出射辐射亮度，由该点自身辐射与所有入射光经 BRDF 反射的贡献组成。

**单一光源形式：**

$$L_r(x, \omega_r) = L_e(x, \omega_r) + L_i(x, \omega_i)\,f(x, \omega_i, \omega_r)\,(\omega_i \cdot n)$$

各项含义：反射光（输出图像）$=$ 自身向外辐射 $+$ 入射光（来自光源）$\times$ BRDF $\times$ 入射角的余弦。

**多光源求和形式：**

$$L_r(x, \omega_r) = L_e(x, \omega_r) + \sum L_i(x, \omega_i)\,f(x, \omega_i, \omega_r)\,\cos\theta_i\,d\omega_i$$

**用积分代替求和：**

$$L_r(x, \omega_r) = L_e(x, \omega_r) + \int_{\Omega} L_i(x, \omega_i)\,f(x, \omega_i, \omega_r)\,\cos\theta_i\,d\omega_i$$

**多表面相互反射**：当入射光来自其它表面点 $x'$ 时，$L_i(x,\omega_i)$ 被替换为该点的反射辐射亮度 $L_r(x', -\omega_i)$：

$$L_r(x, \omega_r) = L_e(x, \omega_r) + \int_{\Omega} L_r(x', -\omega_i)\,f(x, \omega_i, \omega_r)\,\cos\theta_i\,d\omega_i$$

此时方程左端的反射光（输出图像）未知，被积分号内的反射光也未知，构成递归。

### 2. 渲染方程（Rendering Equation）

将上式写在半球 $H^2$ 上即为渲染方程：

$$L_r(p, \omega_r) = L_e(p, \omega_r) + \int_{H^2} L_i(p, \omega_i)\,f_r(p, \omega_i, \omega_r)\,\cos\theta_i\,d\omega_i$$

渲染方程难以得到解析解。目前有两种基本求解思路：

- **光线追踪 + 蒙特卡洛**：对光路采样，统计估计。
- **辐射度方程 + 有限元**：离散化形成矩阵方程。

## 七、蒙特卡洛求解渲染方程

### 1. 蒙特卡洛近似

对渲染方程的积分用蒙特卡洛方法近似：

- 生成对某一角度分布 $p(\omega)$ 的采样；
- $p(\omega)$ 的选择：半球均匀分布、针对 BRDF 的重要性采样、针对光源位置的重要性采样。

近似结果（$N$ 个样本）：

$$L_r(p, \omega_r) \approx L_e(p,\omega_r) + \frac{1}{N}\sum_{j=1}^{N} \frac{f_r(p, \omega_j, \omega_r)\,L_i(p, \omega_j)\,\cos\theta_j}{p(\omega_j)}$$

### 2. 直接光照的 Path Tracing 伪代码

只考虑直接光照时，可用不同采样策略：

**均匀采样：**

```text
DirectLightingSampleUniform(p, ωo) {
    ωi = hemisphere.sampleUniform();      // uniform random sampling
    pdf = 1.0 / (2 * pi);
    if (scene.shadowIntersection(p, ωi))  // Shadow ray
        return 0;
    else L = lights.radiance(intersect(p, ωi), –ωi);
    return L * p.brdf(ωi, ωo) * costheta / pdf;
}
```

**BRDF 重要性采样：**

```text
DirectLightingSampleBRDF(p, ωo) {
    ωi, pdf = p.brdf.sampleDirection();   // Imp. Sample BRDF
    if (scene.shadowIntersection(p, ωi))  // Shadow ray
        return 0;
    else L = lights.radiance(intersect(p, ωi), –ωi);
    return L * p.brdf(ωi, ωo) * costheta / pdf;
}
```

**光源重要性采样：**

DirectLightingSampleLights(p, ωo) {

## 八、递归方程与全局光照

### 1. 挑战：递归方程

反射光取决于入射光：

$$L_r(p, \omega_r) = \int_{H^2} f_r(p, \omega_i \to \omega_r)\,L_i(p, \omega_i)\,\cos\theta_i\,d\omega_i$$

但入射光又取决于场景中另一个点的反射光。定义**传输函数** $tr(p, \omega)$ 为场景表面上第一个与射线 $(p, \omega)$ 相交的点。在辐射度传输上有：

$$L_r\big(tr(p, \omega_i), -\omega_i\big) = L_i(p, \omega_i)$$

即在 $p$ 点以角度 $\omega_i$ 接收到的辐射亮度，与 $p'$ 点朝 $-\omega_i$ 发出的辐射亮度相等。代入得：

$$L_r(p, \omega_r) = L_e(p, \omega_r) + \int_{H^2} L_r\big(tr(p, \omega_i), -\omega_i\big)\,f_r(p, \omega_i, \omega_r)\,\cos\theta_i\,d\omega_i$$

### 2. 积分方程形式

渲染方程是**第二类 Fredholm 积分方程**的标准形式：

$$L_r(x, \omega_r) = L_e(x, \omega_r) + \int_{\Omega} L_r(x', -\omega_i)\,f(x, \omega_i, \omega_r)\,\cos\theta_i\,d\omega_i$$

对应标准形式：

$$I(u) = e(u) + \int I(v)\,K(u, v)\,dv$$

其中 $K(u,v)$ 称为**方程核**。

### 3. 线性算子方程与诺依曼级数

将积分核记为**光传输算子** $K$，渲染方程可写成线性算子方程：

$$L = E + KL$$

可离散为矩阵方程（$L$、$E$ 是向量，$K$ 是反射一次的光传输矩阵，可分解为 $K = RT$，$R$ 为反射函数、$T$ 为传输函数）。求解：

$$L = E + KL \;\Longrightarrow\; (I - K)L = E \;\Longrightarrow\; L = (I - K)^{-1}E = (I + K + K^2 + K^3 + \cdots)E$$

直觉上，这是光线连续反射结果的和：$E$ 为光源直射，$KE$ 为一次反射，$K^2E$ 为两次反射……该级数计算了静态场景中的表面光场。

### 4. 全局光照渲染

全局光照即对所有可能的光路求和：$\sum_{i=0}^{\infty} K^i(L_e)$。随着反射次数增加（一次、两次、四次、八次、十六次……），渲染结果逐渐收敛到完整的全局光照。

**挑战**：

- 如何生成所有可能的光路；
- 如何对空间采样使计算最有效。

## 九、Path Tracing 与无限递归

### 1. 蒙特卡洛直接求和

BRDF 重要性采样下的递归 Path Tracing 伪代码：

```text
EstRadianceIn(x, ω) {
    p = intersectScene(x, ω);              // 求反射交点
    L = p.emittedLight(–ω);                // 光源（自发光）
    ωi, pdf = p.brdf.sampleDirection(–ω);  // BRDF 重要性采样
    L += EstRadianceIn(p, ωi) * p.brdf(ωi, –ω) * costheta / pdf;
    return L;
}
```

**问题：无限次递归。**

### 2. 无限递归问题

如何对无穷光路求和？注意到高次反射能量几乎以指数下降。

- **想法 1：取前 $N$ 次反射结果**——记录反射次数到 $N$ 停止。问题：取样再多也存在截断误差（有偏）。

### 3. 俄罗斯轮盘赌（Russian Roulette）——无偏随机终止

**想法**：以一个概率终止递归。在递归的每一步（每次反射）都以一个概率直接退出，假设继续递归的概率为 $p_r$，则期望递归 $1/(1 - p_r)$ 次，结果**无偏**。

将结果修正为：

$$X_r = \begin{cases} \dfrac{X}{p_r}, & \text{以概率 } p_r \text{ 继续递归} \\[2mm] 0, & \text{终止递归} \end{cases}$$

**无偏证明**：

$$E[X_r] = p_r \cdot E\!\left[\frac{X}{p_r}\right] + (1 - p_r)\cdot E[0] = E[X]$$

期望上结果相同。

**如何选择 $p_r$**（应在以下情形提高终止概率）：

- 计算开销过大时；
- 光照能量减小、对结果贡献太小时；
- BRDF 中贡献太小时。

俄罗斯轮盘赌给出了一个无偏、有限的算法，用于估算无限空间光路上的积分 $\sum_i K^i(L_e)$。

## 十、拆分渲染方程与 Path Tracing 结果

### 1. 按反射次数拆分

$$\text{EstRadianceIn}(x, \omega) = \text{EstRadianceOut}(p, -\omega)$$

需要将经过 $p$ 点的光路累加，可以按经过 0、1、2、3……次反射来分类。考虑 $p$ 点不同反射数的贡献：

- **0 次反射**：从 $p$ 发出的光（$p$ 是光源，即自发光）；
- **一次反射**：从光源到 $p$ 点再到视点（即"直接光照"）；
- **大于一次反射**：从光源到任意其他点 $p'$（$p'$ 经过 $\ge 1$ 次反射）再经过 $p$ 点入射到视点（即"间接光照"）。

### 2. 收敛效果

- **直接光照**对应 0/1 次反射；
- **Path Tracing**对所有光照（直接 + 间接）求和。

随每像素采样路径数增加（如 1 次、32 次、1024 次），蒙特卡洛噪声逐渐降低，图像收敛到真实的全局光照效果。
