# 第7章 光栅图形学

*本章介绍光栅图形显示原理、走样与反走样、基本图元（直线、圆、字符）的扫描转换算法、多边形的扫描转换与区域填充，以及隐藏线/隐藏面消除算法。*

## 一、光栅图形显示技术

### 基本概念

- 光栅显示器上的图像是由**光栅（raster）**形成的。
- **光栅**是一组互相平行的**水平扫描线（scanline）**，每行扫描线由大小一致的显示单元组成的显示序列构成。每一显示单元称为一个**像素（picture element, pixel）**，可显示给定的颜色或灰度。
- 光栅显示器将显示**图元（primitive）**（如线、文字、填充颜色或图案区域等），以像素的形式存储到一个**刷新缓冲器（refresh buffer）**中。

### 像素（pixel）

- 最小可编程物理单元。
- 具体物理形式有多种：单一物理单元 / 复合物理单元（三原色）。
- 排列形状可为四边形、六角形等。

### 图元（primitive）

- 描述图形元素的基本函数，可直接调用，如点、直线等；但圆不是基本图元。
- **缓冲器（buffer）**：常见有刷新缓冲器（refresh buffer）、深度缓冲器（Z-buffer）等。

## 二、随机扫描与光栅扫描

### 随机扫描技术

- 按照显示命令的任意顺序，将电子束从一个端点偏转到另一个端点。
- 单枪顺序扫描。
- 屏幕上的点不可编程。

### 光栅图形技术

- 像素可编程。
- 可并行处理。
- 可对显示区域填充颜色或图案。
- 存储的图像易于操作。

## 三、走样与反走样

### 走样（Aliasing）

- 对于光栅系统，需要用光栅网格上的像素来近似地描绘平滑的直线、多边形以及圆、椭圆等曲线图元的边界。
- 这会引起锯齿状、阶梯状的边界，该现象称为**走样（aliasing）**，又称**锯齿现象（Jaggies）**。

### 反走样（Anti-Aliasing）

- 抑制或消除走样现象的技术称为**反走样（antialiasing）**。
- 核心思路：颜色不再非 0 即 1，而是**引入中间颜色值**，缓解视觉上的突兀感。
- 常见反走样方案：在采样前进行模糊处理（**预过滤，prefiltering**）。
- 处理顺序不同会有不同效果，可分为"先采样后过滤"与"先过滤后采样"两种思路。

## 四、光栅化

- 如何使光栅图形最完美地逼近实际图形，是光栅图形学要研究的核心内容。
- 确定最佳逼近图形的像素集合，并用指定的颜色和灰度设置这些像素的过程，叫做图形的**扫描转换（scan conversion）**，或称**光栅化（rasterization）**。

## 五、简单二维图元的生成（OpenGL）

### 绘制流程

作为图形硬件的软件接口，OpenGL 最主要的工作就是将二维及三维物体绘制到帧缓存。绘制过程主要有以下 3 步：

1. 定义几何要素，构建物体在计算机内的表示；确定各物体在三维空间中的方位，选取场景观察点。
2. 计算物体表面需要显示的颜色，这些颜色可以直接赋值，或根据光照条件及表面纹理计算得到。
3. **光栅化**：把物体的几何描述和颜色信息转换为屏幕的像素。

### 点的绘制

- OpenGL 允许采用 `glPointSize()` 函数由用户自定义点在屏幕上的显示尺度（缺省宽度为 1.0）。

### 直线的绘制

- 直线由两端点定义。只要把 `glBegin()` 的参数设为 `GL_LINES`，OpenGL 即可通过 `glBegin()` / `glEnd()` 函数对来绘制直线。
- 此时函数对中：第一个顶点为第一条直线的起点，第二个顶点为该直线的终点，第三个顶点为第二条直线的起点，依次类推。

## 六、直线的扫描转换算法

直线的扫描转换算法主要有两种：

- **基本增量算法（DDA, Digital Differential Analyzer，数字微分分析法）**
- **Bresenham 算法**

其中 Bresenham 算法是计算机图形学领域使用最为广泛的直线扫描转换算法。

### 1. 基本增量算法（DDA 算法）

直线 $y = mx + h$ 满足微分方程：

$$\frac{dy}{dx} = m = \frac{Dy}{Dx} = \frac{y_2 - y_1}{x_2 - x_1}$$

沿扫描线取 $Dx = 1$，则每步 $x$ 增加 1、$y$ 增加 $m$，对每个 $x$ 画出最接近的整数 $y$：

```c
for (x = x1; x <= x2; x++) {
    y += m;
    write_pixel(x, round(y));
}
```

**斜率大的直线问题**：当斜率 $|m| > 1$ 时，$x$ 增加 1、$y$ 增加 $m$ 会使点过于稀疏。解决办法是**利用对称性，交换 $x$ 与 $y$ 的角色**（沿 $y$ 方向步进）。

### 2. Bresenham 算法

#### 特点

- 所有计算都是简单的整数运算：加法、减法、乘以 2（移位）。
- 保证线是连续的，其中每个点都精确绘制 1 次。
- 也称为**中点线算法**。

#### 基本思想

通过各行、各列像素中心构造一组虚拟网格线。按照直线起点到终点的顺序，计算直线与各垂直网格线的交点，然后根据误差项的符号确定该列中与交点最近的像素。

- 每次 $x+1$，$y$ 的递增（减）量为 0 或 1，取决于实际直线与最近光栅网格点的距离，该距离最大误差为 0.5。
- 误差项 $d$ 的初值为 0，每步 $d = d + k$（$k$ 为斜率），一旦 $d \geq 1$ 就把它减去 1，保证 $d$ 始终在 0、1 之间。
- 关键目标：提高效率，只用整数加法。

#### 改进 1：令 $e = d - 0.5$

- $e > 0$：$y$ 方向递增 1；$e < 0$：$y$ 方向不递增；$e = 0$：可任取上下光栅点显示。
- 初值 $e_{init} = -0.5$。
- 每走一步 $e = e + k$，其中 $k = \dfrac{dy}{dx}$。
- 如果 $e > 0$，则 $e = e - 1$。

#### 改进 2：消除小数（乘以 $2dx$）

由于算法中只用到误差项的符号，可以用 $e = e \cdot 2 \cdot dx$ 来替换 $e$，从而消除除法和小数：

- 初值 $e_{init} = -dx$。
- 每走一步 $e = e + 2 \cdot dy$。
- 如果 $e > dx$，那么 $e = e - 2 \cdot dx$（此时 $y$ 递增 1）。

**算法步骤（改进 2，以 $0 \le k \le 1$ 为例）**：

1. 输入直线的两端点 $P_0(x_0, y_0)$ 和 $P_1(x_1, y_1)$。
2. 计算初始值 $dx$、$dy$，置 $e = -dx$、$x = x_0$、$y = y_0$。
3. 绘制点 $(x, y)$。
4. 更新 $e = e + 2 \cdot dy$，判断 $e$ 的符号：若 $e > dx$，则 $(x, y)$ 更新为 $(x+1, y+1)$，同时 $e = e - 2 \cdot dx$；否则 $(x, y)$ 更新为 $(x+1, y)$。
5. 当直线没有画完时，重复步骤 3、4。

#### DDA 与 Bresenham 的联系与区别

- 二者很相似，都是"加斜率"。
- 区别：DDA 每次求一个新的 $y$ 后**取整**来画；Bresenham 则通过**判断误差项符号**来决定取上下两个点中的哪一个。
- Bresenham 集中了 DDA 的优点，且只用整数运算、应用范围更广泛。

## 七、圆的扫描转换（中点画圆法）

利用圆的对称性：选取 $x = 0$、$y = 0$、$y = x$、$y = -x$ 四条直线作为对称轴将圆**八等分**，只需画出一段圆弧（如第一象限 $y = x$ 上方的弧），其余七段可直接对称获得。

- 对于第一象限 $y = x$ 上方的圆弧，任意点斜率大小不超过 1。
- 因此若当前圆弧在像素 $(x_i, y_i)$ 上，那么在 $x_i + 1$ 位置上，纵坐标只能是 $y_i$ 或 $y_i - 1$。

### 判别函数

选取两种情况的中点 $(x_i + 1,\ y_i - 0.5)$，若其在圆内，说明纵坐标 $y_i$ 更近，否则选取 $y_i - 1$。于是构造判别量：

$$d_i = (x_i + 1)^2 + (y_i - 0.5)^2 - r^2$$

判断 $d_i$ 与 0 的关系，并递推：

- 若 $d_i < 0$（中点在圆内，取 $y_i$）：
  $$d_{i+1} = (x_i + 2)^2 + (y_i - 0.5)^2 - r^2 = d_i + 2x_i + 3$$
- 若 $d_i \geq 0$（中点在圆外，取 $y_i - 1$）：
  $$d_{i+1} = (x_i + 2)^2 + (y_i - 1.5)^2 - r^2 = d_i + 2(x_i - y_i) + 5$$

### 初始条件与算法步骤

初始条件：$x_0 = 0$，$y_0 = r$，

$$d_0 = 1 + (r - 0.5)^2 - r^2 = 1.25 - r$$

**算法步骤**：

1. 设置 $x$、$y$、$d$、$r$ 的初始值如上。
2. 若横坐标 $x$ 已经大于纵坐标 $y$，说明脱离了八分之一圆弧，退出。
3. 绘制点 $(x, y)$（并对称绘制其余七个点）。
4. 判断 $d$ 是否小于 0：若是，则迭代为 $d = d + 2x + 3$；否则迭代为 $d = d + 2(x - y) + 5$ 并将 $y$ 减一。然后 $x$ 加一，回到步骤 2。

## 八、字符的生成

生成字符有两种基本方法：

- **轮廓法**：将字符定义为一条曲线或多边形的轮廓，然后进行扫描转换。表达精确、可任意缩放，但计算开销很大。
- **位图法（点阵法）**：对给定字体的每一个字符，生成一个小型的矩形位图。位图中某位为 1 表示字符的笔画经过此位，为 0 表示笔画不经过此位。这一过程即**字库设计**。

## 九、光栅图形的基本概念

### 关于光栅图形

- 本质：**点阵表示**。
- 特点：面着色，画面明暗自然、色彩丰富。
- 与线框图相比：更加生动、直观、真实感强。

### 关于平面多边形

图形学中的多边形一般指**无自相交的简单多边形**。其两种表示方式：

- **顶点表示**：用多边形的有序顶点序列表示多边形。
- **点阵表示**：用位于多边形内部的像素集合来表示多边形。

#### 顶点表示

- 优点：直观；几何意义明显；存储量小。
- 不足：难以判断哪些像素位于多边形内部；不能直接用于多边形着色。

#### 点阵表示

- 优点：便于用**帧缓冲器（frame buffer）**表示图形；是面着色所需的图形表示。
- 缺点：丢失了几何信息；占用存储空间多。

## 十、多边形的扫描转换

**多边形的扫描转换**即把顶点表示转换为点阵表示：

- 从多边形的给定边界出发，求出其内部的各个像素；
- 并给帧缓冲器中各个对应元素设置相应的灰度或颜色。

## 十一、点阵表示的区域填充

### 区域的定义与表示

- **区域的定义**：已经表示成点阵的像素集合。
- **内部表示**：把给定区域内的像素枚举出来。区域内所有像素都着同一种颜色，区域边界像素不能着该颜色。
- **边界表示**：把区域边界上的像素枚举出来。边界上所有像素都着同一种颜色，区域内部像素不能着该颜色。

### 区域的类型（连通性）

- **四连通区域**：区域内任意两个像素，从一个像素出发，可以通过上、下、左、右四种运动到达另一个像素。
- **八连通区域**：区域内任意两个像素，从一个像素出发，可以通过水平、垂直、正对角线、反对角线共八种运动到达另一个像素。

### 内部表示区域的种子填充算法（四连通）

假设内部表示区域为 $G$，其中像素原有颜色为 $G_0$，需要填充的颜色为 $G_1$。算法需提供一个种子点 $(x, y)$，其颜色为 $G_0$：

```c
Flood_Fill_4(x, y, G0, G1)
{
    if (GetPixel(x, y) == G0)   // GetPixel(x,y) 返回(x,y)的颜色
    {
        SetPixel(x, y, G1);     // 将(x,y)添上颜色G1
        Flood_Fill_4(x - 1, y, G0, G1);
        Flood_Fill_4(x, y + 1, G0, G1);
        Flood_Fill_4(x + 1, y, G0, G1);
        Flood_Fill_4(x, y - 1, G0, G1);
    }
}
```

### 边界表示区域的种子填充算法（四连通）

```c
Fill_Boundary_4_Connected(x, y, BoundaryColor, InteriorColor)
// (x,y): 种子像素坐标
// BoundaryColor: 边界像素颜色；InteriorColor: 需填充的内部像素颜色
{
    if (GetPixel(x, y) != BoundaryColor &&
        GetPixel(x, y) != InteriorColor)
    {
        SetPixel(x, y, InteriorColor);                       // 置成填充颜色
        Fill_Boundary_4_Connected(x, y + 1, BoundaryColor, InteriorColor);
        Fill_Boundary_4_Connected(x, y - 1, BoundaryColor, InteriorColor);
        Fill_Boundary_4_Connected(x - 1, y, BoundaryColor, InteriorColor);
        Fill_Boundary_4_Connected(x + 1, y, BoundaryColor, InteriorColor);
    }
}
```

## 十二、多边形扫描转换算法

### 1. 逐点判断算法

- 思想：逐个像素判别其是否位于多边形内部，这是一个典型的计算几何问题。
- **射线法**：从当前像素发射一条射线，计算射线与多边形的交点个数。
  - 内部：奇数个交点。
  - 外部：偶数个交点。

**算法描述**：

```c
for (y = 0; y <= y_resolution; y++)
    for (x = 0; x <= x_resolution; x++)
    {
        if (inside(polygon, x, y))
            setpixel(framebuffer, x, y, polygon_color);
        else
            setpixel(framebuffer, x, y, background_color);
    }
```

**不足**：

- 速度慢：几十万甚至几百万像素的多边形内外判断，需要大量求交、乘除运算。
- 没有考虑像素之间的联系。
- 结论：逐点判断算法需要改进。

### 2. 相邻像素之间的连贯性

**扫描线算法**充分利用了相邻像素之间的连贯性，避免了对像素的逐点判断和求交运算，从而提高了算法效率。

**连贯性（coherence）**分为三类：区域连贯性、扫描线连贯性、边的连贯性。

#### 区域连贯性

- 指多边形所定义区域内部相邻的像素具有相同的性质（例如相同的颜色）。
- 两条扫描线之间的长方形区域被多边形分割成若干**梯形**（三角形可看作退化的梯形）。梯形的底边为扫描线，梯形的腰为多边形的边或窗口边缘。
- 梯形分为两类——位于多边形内部和外部，两类梯形相间排列：相邻的两个梯形必有一个位于多边形内部，另一个在外部。
- **推论**：如果某梯形属于多边形内（外），那么该梯形内所有点均属于多边形内（外）。即把逐点判断升级为**区域判断**。

#### 扫描线连贯性

- 是区域连贯性在一条扫描线上的反映。
- 扫描线与多边形的交点个数为偶数（如 1, 2, 3, 4, 5, 6）。区间 (1,2)、(3,4)、(5,6) 位于多边形内部，其余区间位于外部，两类区间相间排列。
- **推论**：如果某交点区间属于多边形内（外），那么该区间内所有点均属于多边形内（外）。即把逐点判断升级为**区间判断**。

#### 边的连贯性

- 边的连贯性：直线的线性性质在光栅上的表现。
- 相邻扫描线（设 $y_1 = y_{11} + 1$）与多边形同一条边的交点存在如下关系：

$$\frac{y_1 - y_{11}}{x_1 - x_{11}} = k \quad\Rightarrow\quad x_1 = x_{11} + \frac{1}{k}$$

- 当知道扫描线与一条边的一个交点之后，即可通过上述公式用**增量算法**迅速求出其它交点。
- **推论**：边的连贯性是连接区域连贯性和扫描线连贯性的纽带。即"扫描线连贯性 + 边连贯性 = 区域连贯性"。

### 3. 扫描线填充算法

**核心思想（从下到上扫描）**：按扫描线顺序，计算扫描线与多边形的相交区间，再用要求的颜色显示这些区间的像素，即完成填充。

区间的端点通过计算扫描线与多边形边界线的交点获得。例如扫描线 $y = 3$ 与多边形边界相交于 4 点 $(2,3)$、$(4,3)$、$(7,3)$、$(9,3)$，定义了 $x \in [2,4]$ 与 $x \in [7,9]$ 两个落在多边形内的区间，区间内像素应取填充色。

**算法步骤**：

1. 确定多边形所占的最大扫描线范围，求出顶点 $y$ 坐标的最小、最大值（$y_{min}$ 和 $y_{max}$）。
2. 从 $y_{min}$ 到 $y_{max}$，每次用一条扫描线进行填充。
3. 对一条扫描线的填充过程分为四步：
   - a) 求交点；
   - b) 把所有交点按 $x$ 递增顺序排序；
   - c) 交点配对（第一个与第二个、第三个与第四个……）；
   - d) 区间填色：把相交区间内的像素置成多边形颜色，区间外的置成背景色。

### 4. 顶点交点的取舍问题（奇异情况）

当扫描线恰好与多边形顶点相交时，交点的取舍需保证**交点总数为偶数**。

**解决方案**：

- 若共享顶点的两条边分别落在扫描线的两边，交点只算一个。
- 若共享顶点的两条边在扫描线的同一边，则该交点作为 0 个或 2 个。
- 具体判断：检查共享顶点的两条边的另外两个端点的 $y$ 值，按其中大于交点 $y$ 值的个数来决定交点数——
  - 两端点 $y$ 值都小于交点 $y$ 值：交点作为 0 个；
  - 两端点 $y$ 值都大于交点 $y$ 值：交点作为 2 个。

### 小结

- 基本概念。
- 区域填充：四连通/八连通区域；连通区域的种子填充算法。
- 多边形的扫描转换：逐点判断算法、扫描线算法；连贯性（区域、扫描线、边）；奇异点的处理。
- 多边形扫描转换与区域填充的比较。

## 十三、隐藏线、隐藏面消除算法（消隐）

### 消隐的基本概念

- **消隐（hidden line / face removal）**：相对于观察者，确定场景中哪些物体是可见或部分可见的，哪些是不可见的。
- 消隐可以增加图形的真实感：将三维空间投影到二维平面后，通过确定物体的前后关系可获得更多信息。
- 没有消隐的图形具有**二义性**（如立方体线框图，可解释为不同顶点离视点最近）。消隐是图形学中非常重要的一个基本问题。

### 算法权衡

- 消隐问题的复杂性导致许多精巧的算法，不同算法适合不同应用环境：
  - 实时模拟：要求消隐算法速度快，生成的图形质量一般。
  - 真实感图形生成：要生成高质量图形，消隐算法速度通常较慢。
- 权衡因素：**计算效率**与**图形质量**。

### 消隐与排序、连贯性

- **排序**：判断场景中物体全部或部分与视点之间的远近。
- **连贯性**：场景中物体或其投影所表现出来的相似程度。
- 消隐算法的效率很大程度上取决于：排序的效率，以及各种连贯性的利用。

### 消隐的分类（按坐标空间）

按算法实现时所在的坐标系（空间）分类：**图像空间消隐**与**物体空间消隐**。

#### 图像空间消隐

```c
for (图像中每一个像素) {
    确定由投影点与像素连线穿过的、距离观察点最近的物体；
    用适当的颜色绘制该像素；
}
```

- 特点：在屏幕坐标系中进行，生成的图像受限于显示器分辨率。
- 算法复杂度 $O(nN)$：场景中每一个物体要和屏幕中每一个像素进行排序比较，$n$ 为物体个数，$N$ 为像素个数。
- 代表方法：z 缓冲器算法、扫描线算法等。

#### 物体空间消隐

```c
for (世界坐标系中的每一个物体) {
    确定未被遮挡的物体或部分物体；
    用恰当的颜色绘制出可见部分；
}
```

- 特点：算法精度高，与显示器分辨率无关，适合精密的 CAD 工程领域。
- 算法复杂度 $O(n^2)$：场景中每一个物体都要和其他物体进行排序比较，$n$ 为物体个数。
- 代表方法：背面剔除、表优先级算法等。

#### 两种方法的比较

- 理论上：若 $n$（物体数）< $N$（像素数），则物体空间算法计算量 $O(n^2)$ 小于图像空间算法 $O(nN)$。
- 实际应用中通常会考虑画面的连贯性，所以图像空间算法的效率有可能更高。
- 也存在物体空间和图像空间的**混合消隐算法**。

### 物体空间：表优先级算法（画家算法）

- 原理：离视点近的物体可能遮挡离视点远的物体。
- 在物体空间确定物体之间的可见性顺序（离视点远近），**由远及近**地绘制出正确的图像——即**画家算法（油画家算法）**。
- 条件：场景中物体在 $z$ 方向上没有相互重叠。

### 图像空间：z 缓冲器算法（Z-buffer）

- z（深度）缓冲器算法属于图像空间算法。
- z 缓冲器是帧缓冲器的推广：
  - 帧缓冲器：存储像素的颜色属性。
  - z 缓冲器：存储对应像素的 $z$ 值。
- 假设在视点坐标系 $(oxyz)$ 中，投影平面为 $z = 0$，视线方向沿 $z$ 轴负方向，投影为平行投影。深度值就是物体沿视线（$z$）方向与视点的距离。离视点近的物体遮挡远的物体——约定 **$z$ 值越大，离视点越近**。

**算法描述**：

1. 帧缓冲器中的颜色置为背景颜色。
2. z 缓冲器中的 $z$ 值置成最小值（离视点最远）。
3. 以任意顺序扫描各多边形，对多边形中的每一像素：
   - a) 计算其深度值 $z(x, y)$；
   - b) 比较 $z(x, y)$ 与 z 缓冲器中已有值 $z_{buffer}(x, y)$：若 $z(x, y) > z_{buffer}(x, y)$，则计算该像素 $(x, y)$ 的光亮属性并写入帧缓冲器，同时更新 $z_{buffer}(x, y) = z(x, y)$。

**其它应用**：阴影算法——以光源为视点做一次 z 缓冲器即可生成阴影。

**优点**：

- 算法复杂度 $O(nN)$：对给定图像空间 $N$ 固定，复杂度只随场景复杂度线性增加。
- 无须排序：物体可按任意顺序写入帧缓冲器和 z 缓冲器，节省了排序时间。
- 适合任何几何物体（能计算与直线的交点）。
- 适合并行实现（硬件加速）。

**不足**：

- z 缓冲器需占用大量存储单元。例如大规模复杂场景中深度范围可能达 $10^6$，一个像素需 24 bit 存储深度信息；若分辨率为 $1280 \times 1024$，则深度缓冲器需约 4 MB 存储空间。
- 深度的采样与量化会带来走样现象。
- 难以处理透明物体。
- 解决存储问题的办法：逐区域进行 z 缓冲器消隐。

### 物体空间：背面剔除算法

利用视线方向 $V$ 和物体表面法向 $N$ 之间的关系判断面的可见性：

- $N \cdot V < 0$：不可见（背面）。
- $N \cdot V \geq 0$：可见（正面）。

**适用范围**：

- 背面剔除适用于**凸多面体**，不适用于凹多面体或其它复杂物体（对于复杂物体，简单的背面剔除不能实现完全消隐）。
- 适用于场景消隐的**预处理**：先消除一些显然不可见的表面，从而提高其它消隐算法的效率。

### 二维半物体的深度排序

- **二维半（2.5D）物体**的深度值是常数，常见于卡通动画、窗口管理、VLSI 设计、图像合成等。
- 其深度排序算法只需简单地比较各物体的 $z$ 值即可。
